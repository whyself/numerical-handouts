# Chebyshev 插值与 Chebyshev 多项式，范数

<p class="lead">上一讲的插值多项式精确通过每个样本点，却可能在点与点之间剧烈振荡。这一讲先把“节点放在哪里”变成一个优化问题：插值误差里只有节点因子 ω(x) 受节点控制，而让它最矮的正是 Chebyshev 多项式的零点。证明的关键是一张“最优性证书”——n + 1 个交替极值点。随后放宽“必须过点”的要求，转向函数逼近：Bernstein 多项式、近最佳的 Chebyshev 插值、把函数当向量的线性代数、衡量误差的范数，最后停在离散最小二乘的几何图像上。</p>

## 3.1 回顾：精确过点 ≠ 点间逼近得好 <Src p="3" />

上一讲的插值问题：给定 $n$ 个点，要求多项式精确通过它们。

- **存在性**：Lagrange 公式直接构造；
- **唯一性**：次数 $< n$ 的非零多项式不可能有 $n$ 个不同零点；
- **Shamir 秘密分享**：少于阈值的点不能唯一确定多项式；
- **Reed–Solomon 纠错码**：多取一些函数值形成冗余，从而获得纠错能力；
- **但在实数上**：精确通过所有点，不代表在点与点之间逼近得好。

另一条线索是**函数逼近**<span class="en">Approximation</span>：不要求过点。Weierstrass 定理告诉我们，闭区间上的连续函数可以被多项式一致地任意逼近（3.11 节给出一个构造性证明）。

::: qa 先猜一猜：用等距节点对 f(x) = 1/(1 + 25x²) 在 [−1, 1] 上做插值，节点越多，插值多项式的最大误差就越小吗？ @P3
**不会**。11 个等距节点时最大误差已经约为 1.92，节点再多，两端的振荡只会更剧烈（这就是 **Runge 现象**<span class="en">Runge phenomenon</span>）。精确过点并不能阻止多项式在点与点之间“甩”出去，问题集中在区间两端。本讲前半部分要回答：同样 11 个节点，只改位置，能把误差降到多少？（答案约 0.11，见 3.9 节。）
:::

## 3.2 插值余项：节点如何进入误差 <Src p="4" />

::: def 插值余项定理 @P4
设 $f$ 在包含 $x_1,\dots,x_n$ 与 $x$ 的区间上 $n$ 阶连续可导，$P_f$ 是 $f$ 在互不相同的节点 $x_1,\dots,x_n$ 上的次数 $< n$ 的插值多项式，记**节点因子**

$$
\omega_n(t) = \prod_{j=1}^{n} (t - x_j).
$$

则对任意 $x$，存在 $\xi_x$ 位于 $x_1,\dots,x_n,x$ 所张成的区间内，使

$$
f(x) - P_f(x) = \frac{f^{(n)}(\xi_x)}{n!}\,\omega_n(x).
$$
:::

**证明**（课件给出三步思路，这里补全每一步的依据）

0. **$x$ 是节点**：两边都是 0（左边因为插值，右边因为 $\omega_n(x) = 0$），任取 $\xi_x$ 即可。下面设 $x$ 不是节点，于是 $\omega_n(x) \ne 0$。<span class="muted">（补充说明）</span>
1. **构造辅助多项式**：令 $\lambda = \dfrac{f(x) - P_f(x)}{\omega_n(x)}$，$q(t) = P_f(t) + \lambda\,\omega_n(t)$。在节点上 $\omega_n(x_j) = 0$，所以 $q(x_j) = P_f(x_j) = f(x_j)$；在 $x$ 处 $q(x) = P_f(x) + (f(x) - P_f(x)) = f(x)$。于是 $q = f$ 在 $x_1,\dots,x_n,x$ 共 $n+1$ 个不同点上成立。
2. **反复用 Rolle 定理**：令 $\phi = f - q$，它 $n$ 阶连续可导，在上述区间 $I$ 内有 $n+1$ 个不同零点。相邻两个零点之间，Rolle 定理给出 $\phi'$ 的一个零点，所以 $\phi'$ 在 $I$ 内至少有 $n$ 个不同零点；同理 $\phi''$ 至少 $n-1$ 个……$\phi^{(n)}$ 至少 1 个，记为 $\xi_x$。
3. **算出 $q^{(n)}$**：$\deg P_f < n$，所以 $P_f^{(n)} \equiv 0$；$\omega_n$ 是首一 $n$ 次多项式，$\omega_n^{(n)} \equiv n!$。因此 $q^{(n)} \equiv \lambda\, n!$，而 $0 = \phi^{(n)}(\xi_x) = f^{(n)}(\xi_x) - \lambda\, n!$，即 $\lambda = f^{(n)}(\xi_x)/n!$。代回 $\lambda$ 的定义就得到余项公式。$\blacksquare$

余项分成两部分：$f^{(n)}(\xi_x)/n!$ 由函数决定，节点无法控制；**节点对误差的全部影响都浓缩在 $\omega_n(x)$ 里**。

::: tldr
插值误差 = $\dfrac{f^{(n)}(\xi_x)}{n!}\,\omega_n(x)$：函数的光滑性管前一项，节点的位置只管 $\omega_n(x) = \prod(x - x_j)$。
:::

## 3.3 今天的问题：先选节点，再面对最坏的光滑函数

### 3.3.1 把节点设计化成一个 min–max 问题 <Src p="5" />

先把一般有限区间通过仿射变换归一化到 $[-1,1]$（缩放细节见 3.9.1）。令 $\mathcal F_M$ 表示所有在 $[-1,1]$ 上 $n$ 阶连续可导、且 $\max_{x\in[-1,1]}|f^{(n)}(x)| \le M$ 的函数。

::: prin 固定节点后，最坏误差恰好由节点因子决定 @P5
对任意 $f \in \mathcal F_M$，

$$
\max_{x\in[-1,1]} |f(x) - P_f(x)| \le \frac{M}{n!}\max_{x\in[-1,1]} |\omega_n(x)|,
$$

而且这个上界在函数类上是紧的：

$$
\sup_{f\in\mathcal F_M}\ \max_{x\in[-1,1]} |f(x) - P_f(x)| = \frac{M}{n!}\max_{x\in[-1,1]} |\omega_n(x)| .
$$
:::

**证明**：

- **上界**：由 3.2 节余项公式，$|f(x) - P_f(x)| = \dfrac{|f^{(n)}(\xi_x)|}{n!}|\omega_n(x)| \le \dfrac{M}{n!}|\omega_n(x)|$，再对 $x$ 取最大。
- **达到上界**：取 $f(x) = Mx^n/n!$，则 $f^{(n)} \equiv M$，$f \in \mathcal F_M$。$x^n - P_{x^n}(x)$ 是首一 $n$ 次多项式（$P_{x^n}$ 次数 $< n$，不影响首项），并且在 $n$ 个节点上都为 0，所以它就是 $\omega_n(x)$（首一 $n$ 次多项式由它的 $n$ 个不同零点唯一确定）。于是 $f - P_f = \dfrac{M}{n!}\omega_n$，误差恰好等于上界。$\blacksquare$

节点设计最终只剩下一个问题：**$\max_{x\in[-1,1]} |\omega_n(x)|$ 怎样才能尽可能小？**

### 3.3.2 先放松，再证明放松是紧的 <Src p="6" />

对上面的光滑函数类，节点设计问题恰好是

$$
\min_{\substack{x_1,\dots,x_n\in[-1,1]\\ x_i\ne x_j\ (i\ne j)}}\ \max_{x\in[-1,1]} |\omega_n(x)| .
$$

每个 $\omega_n$ 都是首一 $n$ 次多项式，于是把候选集合放大到**所有**首一 $n$ 次多项式：

$$
\min_{\substack{p:\ \deg p = n\\ [x^n]p = 1}}\ \max_{x\in[-1,1]} |p(x)| .
$$

- 放松后可行域更大，最优值不会增大：**放松问题的最优值是原问题的下界**。
- 若放松问题的某个最优解恰好有 $n$ 个位于 $[-1,1]$ 的实根，那么它就是某组节点的 $\omega_n$，在原问题中可行，于是它同时解出了原来的选点问题。<span class="muted">（注：严格地说要求这 $n$ 个实根**互不相同**，因为节点要两两不同；Chebyshev 多项式的零点满足这一点，见 3.7 节。）</span>

::: tldr
最坏误差 = $\dfrac{M}{n!}\max|\omega_n|$，所以选节点 = 在首一 $n$ 次多项式里找 $[-1,1]$ 上最“矮”的那个，并希望它的根都是 $[-1,1]$ 内的不同实数。
:::

## 3.4 等距节点的问题出在边界附近 <Src p="7" />

对 11 个等距节点，直接画出 $|\omega_{11}(x)| = \prod_{j=1}^{11} |x - x_j|$（课件 P7 的图与 3.9 节 P18 图中的红线相同，这里用交互演示重画）：

- 最大值不是平均分布的；
- **边界附近的峰最高**（约 $8.53\times10^{-3}$），中间的峰矮得多；
- 要压低最坏值，节点应当**向边界聚集**。

这提示我们：要控制最高峰，应该设法把各处的峰尽量“压平”。

<L03Omega />

::: tldr
等距节点的 $|\omega_n|$ 在两端冒出最高峰；把节点往两端挤，才能把各个峰压到一样高。
:::

## 3.5 Chebyshev 节点：在角度上等距，在 x 轴上不等距 <Src p="8" />

<Fig src="/img/03/p008.jpg" size="sm" cap="上半圆上角度等距的点（蓝），投影到 x 轴（绿）后在两端更密：x_i = cos θ_i" p="8" />

::: def Chebyshev 节点 @P8
在上半圆上取角度等距的点，再投影到 $x$ 轴：

$$
\theta_i = \frac{(2i-1)\pi}{2n},\qquad x_i = \cos\frac{(2i-1)\pi}{2n},\qquad i = 1,\dots,n.
$$

在这些节点上做 Lagrange 插值，得到的就是 **Chebyshev 插值多项式**<span class="en">Chebyshev interpolant</span>。
:::

靠近 $0$ 和 $\pi$ 的角度投影后会自然挤到边界（$\cos$ 在 $\theta = 0, \pi$ 附近变化最慢），正好回应上一节“边界峰最高”的现象。

::: tldr
Chebyshev 节点 = 半圆上等角度的点往 $x$ 轴的投影，天然在两端加密。
:::

## 3.6 Chebyshev 多项式：把圆上的均匀振荡搬到区间上

### 3.6.1 定义 <Src p="9" />

::: def Chebyshev 多项式 @P9
令 $x = \cos\theta$（$\theta \in [0,\pi]$），定义

$$
T_n(x) = \cos(n\theta) = \cos(n\arccos x),\qquad x \in [-1,1].
$$
:::

<Fig src="/img/03/p009.jpg" size="md" cap="T₆ 的图像：在 ±1 之间来回振荡" p="9" />

在变量替换 $x = \cos\theta$ 下，$T_k(x) = \cos(k\theta)$：**Chebyshev 多项式对应余弦函数 $\cos(k\theta)$**。

### 3.6.2 为什么它是多项式，而且能快速算 <Src p="10" />

先看最初几个：$T_0 = \cos 0 = 1$，$T_1 = \cos\theta = x$，$T_2 = \cos 2\theta = 2\cos^2\theta - 1 = 2x^2 - 1$。一般地，由和差化积

$$
\cos((n+1)\theta) + \cos((n-1)\theta) = 2\cos(n\theta)\cos\theta ,
$$

（两边展开：$\cos(n\theta \pm \theta) = \cos n\theta\cos\theta \mp \sin n\theta\sin\theta$，相加后正弦项抵消）把 $x = \cos\theta$ 代入得**三项递推**

$$
\boxed{\,T_{n+1}(x) = 2x\,T_n(x) - T_{n-1}(x)\,} .
$$

**为什么是多项式**<span class="muted">（补充说明：把课件的一句话写成归纳法）</span>：$T_0, T_1$ 是多项式；若 $T_{n-1}, T_n$ 分别是 $n-1$、$n$ 次多项式，则递推式右边是 $n+1$ 次多项式。于是每个 $T_n$ 都是 $n$ 次多项式，并且对所有 $\theta$ 满足 $T_n(\cos\theta) = \cos n\theta$。递推式本身对一切实数 $x$ 都可以用来求值，只需 $O(n)$ 次运算。

**几何上来自余弦；代数上是多项式；计算上只需递推。**

<L03ChebPoly />

::: tldr
$T_n(\cos\theta) = \cos n\theta$，由 $T_{n+1} = 2xT_n - T_{n-1}$ 可知它是 $n$ 次多项式，首项系数 $2^{n-1}$。
:::

## 3.7 等振荡：把“最高峰”平均摊开

### 3.7.1 三条基本性质 <Src p="11" />

<Fig src="/img/03/p011.jpg" size="md" cap="T₅ 在 6 个点上交替达到 ±1：所有峰谷一样高" p="11" />

因为 $T_n(x) = \cos(n\theta)$：

- $|T_n(x)| \le 1$（$x \in [-1,1]$）；
- $T_n(\pm 1) = (\pm 1)^n$（$x = 1$ 对应 $\theta = 0$，$x = -1$ 对应 $\theta = \pi$，$\cos n\pi = (-1)^n$）；
- 在 $n+1$ 个点上**交替**达到 $\pm 1$，所有最高峰都一样高。

这就是**等振荡**<span class="en">Equioscillation</span>。

### 3.7.2 两套余弦点：一个构造答案，一个证明最优 <Src p="12" />

| | 零点：构造答案（construction） | 极值点：最优性证书（certificate） |
|---|---|---|
| 位置 | $x_i = \cos\dfrac{(2i-1)\pi}{2n}$，$i = 1,\dots,n$ | $y_k = \cos\dfrac{k\pi}{n}$，$k = 0,\dots,n$ |
| 来由 | $\cos(n\theta) = 0 \iff n\theta = (2i-1)\pi/2$ | $\cos(n\theta) = \pm1 \iff n\theta = k\pi$ |
| 性质 | $T_n(x_i) = 0$，正是插值节点（3.5 节） | $T_n(y_k) = (-1)^k$，给出 $n+1$ 个交替见证点 |

**零点告诉我们“怎么选”；极值点告诉我们“为什么不可能更好”。**

<span class="muted">补充说明：两组点各自互不相同，因为它们对应的角度 $\theta_i = \frac{(2i-1)\pi}{2n}$ 与 $\frac{k\pi}{n}$ 都落在 $[0,\pi]$ 内且两两不同，而 $\cos$ 在 $[0,\pi]$ 上严格递减。$n$ 次多项式 $T_n$ 已经有 $n$ 个不同零点 $x_i$，所以这就是它的全部零点，都是 $(-1,1)$ 内的单根。</span>

::: prin 构造 + 证书 @P12
这种“给出一个构造 + 给出一份最优性证书”的结构，后面讲线性规划对偶时还会再出现。
:::

::: exam [作业] HW4 问题 1(2)：‖T′ₙ‖∞ = n²
严格证明 Chebyshev 多项式的导数在 $[-1,1]$ 上的最大绝对值恰好是 $n^2$：$\max_{x\in[-1,1]}|T_n'(x)| = n^2$。

**用到**：本节与 3.6 节的 $T_n(\cos\theta) = \cos n\theta$；**思路方向**：在内点用链式法则把 $T_n'(x)$ 写成 $\theta$ 的函数，再估计形如 $\left|\frac{\sin n\theta}{\sin\theta}\right|$ 的量（可以对 $n$ 归纳）；端点 $x \to \pm1$ 时分母趋于 0，按题目提示单独用洛必达法则求极限。
:::

::: tldr
$T_n$ 的 $n$ 个零点 $\cos\frac{(2i-1)\pi}{2n}$ 是节点，$n+1$ 个极值点 $\cos\frac{k\pi}{n}$ 上交替取 $\pm1$，是最优性证书。
:::

## 3.8 Chebyshev 极小极大定理

### 3.8.1 归一化：把 Chebyshev 送进“首一多项式”的可行域 <Src p="13" />

由递推式可归纳得到首项系数 $[x^n]T_n = 2^{n-1}$（$n \ge 1$）：$T_1 = x$ 首项系数 $1 = 2^0$；若 $[x^n]T_n = 2^{n-1}$，则 $T_{n+1} = 2xT_n - T_{n-1}$ 的首项只来自 $2xT_n$，系数为 $2\cdot 2^{n-1} = 2^n$。<span class="muted">（注：课件未写 $n \ge 1$；$T_0 = 1$ 的首项系数是 1 而不是 $2^{-1}$。下面的 $\widehat T_n$ 都默认 $n \ge 1$。）</span>

::: def 首一 Chebyshev 多项式 @P13
$$
\widehat T_n(x) := 2^{1-n}\,T_n(x)\qquad (n \ge 1).
$$

$\widehat T_n$ 是首一 $n$ 次多项式，且 $\displaystyle\max_{x\in[-1,1]}|\widehat T_n(x)| = 2^{1-n}$。
:::

**零点仍然是合法节点**：缩放不改变零点，$\widehat T_n(x_i) = 0$。$\widehat T_n$ 首一、有 $n$ 个不同零点 $x_i$，所以

$$
\widehat T_n(x) = \prod_{i=1}^{n}(x - x_i) = \omega_n(x)\qquad\text{（以 Chebyshev 节点为节点）} .
$$

可行候选已经有了；极值点上它仍交替达到 $\pm 2^{1-n}$。下一步只需证明：**任何首一 $n$ 次多项式都不可能更矮**。

### 3.8.2 定理：下界 + 达到下界 <Src p="14" />

::: def Chebyshev 极小极大定理 @P14
对任意首一 $n$ 次多项式 $p$（$n \ge 1$），

$$
\max_{x\in[-1,1]} |p(x)| \ge 2^{1-n},
$$

而 $\widehat T_n = T_n/2^{n-1}$ 恰好达到这个下界。因此 $\widehat T_n$ 是放松问题的最优解：**普遍下界 + 匹配构造**。
:::

::: qa 课件 P14 留下的问题：为什么 n + 1 个交替极值点就足以证明这个下界？先自己想一想再往下读。 @P14
如果有更矮的首一 $p$，那么在每个极值点上 $p$ 都“够不着” $\widehat T_n$ 的峰或谷，差 $r = p - \widehat T_n$ 的符号就被 $\widehat T_n$ 牵着在 $n+1$ 个点上正负交替，于是 $r$ 至少有 $n$ 个零点；可首项相消后 $r$ 的次数至多 $n-1$——矛盾。下面把每一步写严格。
:::

### 3.8.3 证明：更矮的候选会被迫产生太多零点 <Src p="15–17" />

<Fig src="/img/03/p015.jpg" cap="以 n = 8 示意：在每一对相邻极值点之间，p − T̂ₙ 的符号都被迫翻转，两条曲线至少交叉一次（橙线只表示 |p| < a 的交叉逻辑）" p="15" />

**证明**：记 $a = 2^{1-n}$。反设存在首一 $n$ 次多项式 $p_n$ 使 $|p_n(x)| < a$ 对所有 $x \in [-1,1]$ 成立。令

$$
r(x) = p_n(x) - \widehat T_n(x).
$$

1. **极值点上的符号**<Src p="16" />：在 $y_k = \cos(k\pi/n)$ 上 $\widehat T_n(y_k) = (-1)^k a$。$k$ 为偶数时 $r(y_k) = p_n(y_k) - a < a - a = 0$；$k$ 为奇数时 $r(y_k) = p_n(y_k) + a > -a + a = 0$。即
   $$
   \operatorname{sgn} r(y_k) = -(-1)^k,\qquad k = 0,1,\dots,n,
   $$
   $r(y_0),\dots,r(y_n)$ 严格正负交替。
2. **交替 ⇒ 零点**：$y_0 > y_1 > \dots > y_n$ 两两不同。$r$ 连续，在每个区间 $(y_{k+1}, y_k)$ 两端异号，由介值定理在其中至少有一个零点。这 $n$ 个开区间互不相交，所以 **$r$ 至少有 $n$ 个不同零点**。
3. **次数限制**<Src p="17" />：$p_n$ 与 $\widehat T_n$ 都是首一 $n$ 次多项式，$x^n$ 项相消，$\deg r \le n-1$。
4. **矛盾**：
   - 若 $r \equiv 0$，则 $p_n = \widehat T_n$，$\max|p_n| = a$，与“严格更小”的反设矛盾；
   - 若 $r \not\equiv 0$，次数至多 $n-1$ 的非零多项式至多有 $n-1$ 个不同零点，与第 2 步矛盾。

   <span class="muted">（补充说明：第 1 步已经给出 $r(y_0) \ne 0$，所以 $r \equiv 0$ 的情形其实不会出现；课件分两种情况写是为了完整。）</span>

$$
\text{次数限制零点数} \;+\; \text{交替极值强迫零点} \;\Longrightarrow\; \text{不可能更好}. \qquad\blacksquare
$$

<L03Minimax />

::: tldr
若首一 $p$ 比 $\widehat T_n$ 更矮，$p - \widehat T_n$ 就在 $n+1$ 个交替极值点上正负交替、有 $n$ 个零点，但它次数 $\le n-1$。所以 $\max_{[-1,1]}|p| \ge 2^{1-n}$。
:::

## 3.9 回到最初的问题：最优值 + 一个最优节点设计 <Src p="18" />

::: prin Chebyshev 节点是最坏情形意义下的最优节点 @P18
对任意 $M \ge 0$，

$$
\min_{\substack{x_1,\dots,x_n\in[-1,1]\\ x_i\ne x_j}}\ \sup_{f\in\mathcal F_M}\ \max_{x\in[-1,1]} |f(x) - P_f(x)| = \frac{M}{n!}\,2^{1-n},
$$

一组最优节点是 $x_i = \cos\dfrac{(2i-1)\pi}{2n}$，$i = 1,\dots,n$。
:::

**把三步合在一起**：

1. **固定节点**后，函数类上的最坏误差恰好是 $\dfrac{M}{n!}\max|\omega_n|$（3.3.1）；
2. 每个 $\omega_n$ 都是首一 $n$ 次多项式，由 Chebyshev 极小极大定理 $\max|\omega_n| \ge 2^{1-n}$，所以左边 $\ge \dfrac{M}{n!}2^{1-n}$（3.8）；
3. 取 Chebyshev 节点，$\omega_n = \widehat T_n$，$\max|\omega_n| = 2^{1-n}$，达到下界——**放松解本身就有 $n$ 个不同的合法实根：放松是紧的**（3.3.2）。

<Fig src="/img/03/p018.jpg" size="md" cap="11 个节点的 |ω₁₁(x)|：等距节点（红）两端峰高约 8.5×10⁻³；Chebyshev 节点（绿）所有峰等高 2⁻¹⁰ ≈ 9.8×10⁻⁴" p="18" />

### 3.9.1 从 [a, b] 到 [−1, 1]：误差因子如何缩放 <Src p="34" />

作仿射变换

$$
x = \frac{a+b}{2} + \frac{b-a}{2}t,\qquad x_j = \frac{a+b}{2} + \frac{b-a}{2}t_j .
$$

于是 $x - x_j = \frac{b-a}{2}(t - t_j)$，连乘得

$$
\prod_{j=1}^{n}(x - x_j) = \left(\frac{b-a}{2}\right)^{n}\prod_{j=1}^{n}(t - t_j).
$$

这个变换是 $[-1,1]$ 与 $[a,b]$ 之间的一一对应，节点组也一一对应，而节点因子只差一个与节点无关的常数倍 $\left(\frac{b-a}{2}\right)^n$。因此 $[-1,1]$ 上的 Chebyshev 节点搬回 $[a,b]$ 后仍然最优，最小节点因子为

$$
\left(\frac{b-a}{2}\right)^{n} 2^{1-n}.
$$

<span class="muted">补充说明：结合 3.3.1，在 $[a,b]$ 上用 $n$ 个 Chebyshev 节点插值，若 $|f^{(n)}| \le M$，则 $\max_{[a,b]}|f - P_f| \le \dfrac{M}{n!}\left(\dfrac{b-a}{2}\right)^n 2^{1-n}$（教材 Sauer 3.3 节的误差界）。</span>

## 3.10 插值与函数逼近：约束不同，目标也不同 <Src p="20" />

| 插值 Interpolation | 函数逼近 Approximation |
|---|---|
| 必须经过给定的所有点 | 不要求经过预先指定的点 |
| 有些应用确实需要精确通过样本 | 在允许的一族函数中，寻找与 $f$ 尽可能接近的函数 |
| 选点会强烈影响点与点之间的误差；也可以改用分段插值 | 怎样衡量“接近”，会影响最终答案 |

前半讲解决的是：**在必须插值的约束下，怎样选点？** 现在开始问：**如果不再要求过点，我们能逼近得多好？**

## 3.11 Weierstrass 定理：等距采样也可以构造一致逼近 <Src p="21" />

::: def Bernstein 多项式 @P21
对 $f \in C[0,1]$，

$$
B_nf(x) := \sum_{k=0}^{n} f\!\left(\frac kn\right)\binom nk x^k(1-x)^{n-k} = \mathbb E\!\left[f\!\left(\frac Xn\right)\right],\qquad X \sim \mathrm{Bin}(n,x).
$$
:::

::: qa 上面的 B_n f 用到了等距样本 f(k/n)。它的图像会经过这些样本点吗？ @P21
**一般不会**：$B_nf(j/n) \ne f(j/n)$（$0 < j < n$）一般成立。只有两个端点必然满足 $B_nf(0) = f(0)$、$B_nf(1) = f(1)$：$x = 0$ 时 $X \equiv 0$，$x = 1$ 时 $X \equiv n$，期望里只剩一项。同样使用等距样本，**重建规则**可以完全不同。
:::

::: def Weierstrass 逼近定理（Bernstein 的构造性证明） @P21
对 $f \in C[0,1]$，$\displaystyle\max_{x\in[0,1]}|B_nf(x) - f(x)| \to 0$（$n \to \infty$）。经仿射变换，任意闭区间上的连续函数都可以被多项式一致地任意逼近。
:::

**证明**（课件给出思路：期望、方差、概率论中的 Chebyshev 不等式、一致连续性；这里写完整）<span class="muted">（补充说明）</span>

1. **矩**：$X \sim \mathrm{Bin}(n,x)$ 时 $\mathbb E X = nx$，$\operatorname{Var}X = nx(1-x)$，所以
   $$
   \mathbb E(X/n) = x,\qquad \operatorname{Var}(X/n) = \frac{x(1-x)}{n} \le \frac{1}{4n}
   $$
   （$x(1-x) \le 1/4$）。
2. **一致连续**：$f$ 在闭区间上连续，所以一致连续且有界，记 $\|f\|_\infty = \max|f|$。任给 $\varepsilon > 0$，存在 $\delta > 0$，使 $|s - x| < \delta \Rightarrow |f(s) - f(x)| < \varepsilon$。
3. **拆成两部分**：由 $B_nf(x) = \mathbb E f(X/n)$，
   $$
   |B_nf(x) - f(x)| \le \mathbb E\,\big|f(X/n) - f(x)\big| .
   $$
   在事件 $|X/n - x| < \delta$ 上被积量 $< \varepsilon$；在其补集上被积量 $\le 2\|f\|_\infty$。
4. **Chebyshev 不等式**：$\Pr\big(|X/n - x| \ge \delta\big) \le \dfrac{\operatorname{Var}(X/n)}{\delta^2} \le \dfrac{1}{4n\delta^2}$。
5. 合起来，对**所有** $x \in [0,1]$ 一致地有
   $$
   |B_nf(x) - f(x)| \le \varepsilon + 2\|f\|_\infty\cdot\frac{1}{4n\delta^2} = \varepsilon + \frac{\|f\|_\infty}{2n\delta^2},
   $$
   取 $n > \|f\|_\infty/(2\varepsilon\delta^2)$ 即得 $\max_x|B_nf(x) - f(x)| < 2\varepsilon$。$\blacksquare$

::: warn 关键区别 @P21
Runge 的问题不是“等距采样”本身，而是某些函数上的**高次全局等距插值**。同样的等距样本，换成 Bernstein 的重建规则就一致收敛（代价是收敛很慢）。
:::

<L03Bernstein />

::: tldr
$B_nf(x) = \mathbb E f(X/n)$：$X/n$ 集中在 $x$ 附近，加上一致连续性，就得到一致逼近。它不过样本点，却不会出现 Runge 振荡。
:::

## 3.12 Chebyshev 插值：容易构造，而且接近最佳一致逼近

### 3.12.1 最佳一致逼近误差 <Src p="22" />

::: def 最佳一致逼近误差 @P22
对连续函数 $f : [-1,1] \to \mathbb R$，次数 $< n$ 的最佳一致逼近误差为

$$
E_{n-1}(f) := \min_{\deg p < n}\ \max_{x\in[-1,1]} |f(x) - p(x)| .
$$
:::

一般来说，直接求达到这个最小值的多项式（**最佳一致逼近**<span class="en">Best uniform / minimax approximation</span>）并不容易。

::: prin Chebyshev 插值是近最佳的 @P22
令 $I_nf$ 是在 $n$ 个 Chebyshev 节点上的插值多项式，则存在绝对常数 $C > 0$，使得

$$
\max_{x\in[-1,1]} |f(x) - I_nf(x)| \le C\log n\; E_{n-1}(f),\qquad n \ge 2 .
$$
:::

| 最佳一致逼近 | Chebyshev 插值 |
|---|---|
| 直接优化整个多项式；理论基准最好，但通常难求 | 只需在显式节点采样并插值，只损失 $O(\log n)$ 因子 |

这里**不需要** $f^{(n)}$ 有界：它是与同次数的最佳多项式作**相对**比较。证明见下面两小节（课件补充材料）。

### 3.12.2 Lebesgue 常数：节点决定的插值放大因子 <Src p="35" />

::: def Lebesgue 常数 @P35
给定节点 $x_1,\dots,x_n$，Lagrange 插值写成 $I_nf(x) = \sum_{j=1}^{n} f(x_j)\ell_j(x)$。定义

$$
\Lambda_n := \max_{x\in[-1,1]} \sum_{j=1}^{n} |\ell_j(x)| .
$$
:::

- **对函数值的放大**：对任意 $g$，由三角不等式
  $$
  |I_ng(x)| \le \sum_j |g(x_j)|\,|\ell_j(x)| \le \|g\|_\infty \sum_j|\ell_j(x)| \le \Lambda_n\|g\|_\infty,
  \qquad\text{因此}\quad \|I_ng\|_\infty \le \Lambda_n\|g\|_\infty .
  $$
- **对节点数据扰动的放大**：若 $f(x_j)$ 被扰动为 $f(x_j) + \delta_j$，插值多项式的变化是 $\Delta p = \sum_j \delta_j\ell_j$，同理 $\|\Delta p\|_\infty \le \Lambda_n\max_j|\delta_j|$。

所以 $\Lambda_n$ **只由节点决定**，衡量插值规则本身的最坏放大——它就是第 01 讲“条件数”在插值问题上的版本。

| 节点 | $\Lambda_n$ 的增长 |
|---|---|
| Chebyshev 节点 | $O(\log n)$（事实上 $\Lambda_n \le \frac2\pi\ln n + 1$） |
| 等距节点 | 随 $n$ **指数增长** |

<span class="muted">补充说明：Chebyshev 节点 $\Lambda_n \le \frac{2}{\pi}\ln n + 1$ 的证明较长，课件未给出，可参考 Rivlin 或 Trefethen 的书（见参考文献）；下面的演示数值验证了它。</span>

<L03Lebesgue />

### 3.12.3 为什么只比最佳逼近差 O(log n) <Src p="36" />

**证明**：

1. **插值算子是线性的**，且**对 $\mathcal P_{n-1}$ 不变**：对任意 $p \in \mathcal P_{n-1}$（次数 $< n$ 的多项式），$I_np = p$——$p$ 自己就是过这 $n$ 个点、次数 $< n$ 的多项式，由插值的唯一性即得。
2. 任取 $p \in \mathcal P_{n-1}$，由线性性 $f - I_nf = (f - p) - I_n(f - p)$，于是
   $$
   \|f - I_nf\|_\infty \le \|f - p\|_\infty + \|I_n(f-p)\|_\infty \le (1 + \Lambda_n)\,\|f - p\|_\infty ,
   $$
   第一个不等号是三角不等式，第二个用 3.12.2 的 $\|I_ng\|_\infty \le \Lambda_n\|g\|_\infty$（取 $g = f - p$）。
3. 对 $p$ 取最佳一致逼近，得到
   $$
   \|f - I_nf\|_\infty \le (1 + \Lambda_n)\,E_{n-1}(f) .
   $$
4. 对 Chebyshev 节点 $\Lambda_n = O(\log n)$，所以 $\|f - I_nf\|_\infty \le O(\log n)\,E_{n-1}(f)$；$n \ge 2$ 时 $\log n$ 有正的下界，常数 1 可以并进 $C\log n$。$\blacksquare$

<span class="muted">补充说明：第 3 步用到最佳一致逼近多项式的存在性。它成立，因为 $\mathcal P_{n-1}$ 是有限维的：误差 $\|f - p\|_\infty$ 关于系数连续，而在 $\|p\|_\infty \le 2\|f\|_\infty$ 这个有界闭集外误差都大于 $\|f - 0\|_\infty$，于是最小值在一个紧集上取到。</span>

::: exam [作业] HW4 问题 1(1)：|x| 的最佳一致线性逼近
求 $a, b$ 使 $\sup_{x\in[-1,1]}\big||x| - (ax + b)\big|$ 最小，即求 $f(x) = |x|$ 在 $[-1,1]$ 上无穷范数意义下的最优一次逼近，并论证它为何最优。

**用到**：本节最佳一致逼近 $E_1(f)$ 的定义，以及 3.8 节“交替极值点 = 最优性证书”的论证方式；**思路方向**：先利用 $|x|$ 的对称性猜出最优直线的形状，算出它的误差函数在哪几个点交替取到正负最大值；再反设有更好的直线，看两条直线之差（一个一次多项式）在这些点上的符号会被迫怎样变化。
:::

::: tldr
$\|f - I_nf\|_\infty \le (1 + \Lambda_n)E_{n-1}(f)$：插值误差 = 最佳误差 × 节点的放大因子。Chebyshev 节点 $\Lambda_n = O(\log n)$，等距节点指数增长。
:::

<div class="part-label">PART 4 · 函数空间、范数与最小二乘</div>

## 3.14 函数空间上的线性代数：函数本身就是向量 <Src p="24" />

向量不一定是一列数字。对下面这些函数集合，通常的加法与数乘满足向量空间公理；最直观的一点是运算后仍留在集合内：

$$
f, g \in V,\ c \in \mathbb R \quad\Longrightarrow\quad f + g \in V,\quad cf \in V .
$$

- **熟悉的例子**：$\mathbb R^n$，$\mathbb R[x]$（全体实系数多项式），$\mathcal P_{n-1} = \{p \in \mathbb R[x] : \deg p < n\}$；
- **函数空间**：$C[a,b]$（连续函数），$C^k[a,b]$（$k$ 阶连续可导函数）。

::: def 函数的线性相关与线性无关 @P24
函数族 $\phi_1,\dots,\phi_m$ **线性相关**，当且仅当存在不全为零的 $c_i$，使
$$
\sum_{i=1}^{m} c_i\phi_i(x) = 0,\qquad \forall x .
$$
否则称为**线性无关**。注意“$= 0$”是对定义域内**所有** $x$ 恒成立。
:::

$C[a,b]$ 很大（无穷维），计算机不可能直接在“所有连续函数”里搜索，通常先选一个**有限维子空间**。Weierstrass 定理告诉我们：随着次数增加，多项式空间能够把任意连续函数逼近得任意好。

## 3.15 选一组基，函数就变成一组系数 <Src p="25" />

选定有限维空间 $V = \operatorname{span}\{\phi_1,\dots,\phi_n\}$。若 $\phi_1,\dots,\phi_n$ 线性无关，那么每个 $p \in V$ 都**唯一**写成

$$
p(x) = c_1\phi_1(x) + \dots + c_n\phi_n(x) \quad\Longleftrightarrow\quad c = (c_1,\dots,c_n)^\top \in \mathbb R^n .
$$

（唯一性：若两组系数 $c, c'$ 给出同一个 $p$，则 $\sum(c_i - c_i')\phi_i \equiv 0$，由线性无关 $c = c'$。）

| 单项式基 $1, x, x^2, \dots$ | Chebyshev 基 $T_0, T_1, T_2, \dots$ |
|---|---|
| $p \leftrightarrow$ 一组系数 | 同一个 $p \leftrightarrow$ 另一组系数 |

### 3.15.1 为什么 T₀, …, Tₙ₋₁ 构成 𝒫ₙ₋₁ 的一组基 <Src p="37" />

把 $T_k$ 写成单项式基：由 3.8.1，

$$
T_k(x) = 2^{k-1}x^k + \text{(低次项)}\quad (k \ge 1),\qquad T_0 = 1 .
$$

因此把 $(T_0, T_1, \dots, T_{n-1})$ 用 $(1, x, \dots, x^{n-1})$ 表示的换基矩阵是一个**三角矩阵**，对角元依次为 $1, 1, 2, 4, \dots, 2^{n-2}$，全都非零，所以可逆。于是两组函数都线性无关，并且张成同一个 $n$ 维多项式空间 $\mathcal P_{n-1}$。

<span class="muted">补充说明：“可逆 ⇒ 张成同一空间”的一步：每个 $T_k$ 都是 $1,\dots,x^{n-1}$ 的组合，所以 $\operatorname{span}\{T_k\} \subseteq \mathcal P_{n-1}$；换基矩阵可逆，反过来每个 $x^k$ 也是 $T_0,\dots,T_{n-1}$ 的组合，所以反向包含也成立。$n$ 个向量张成 $n$ 维空间，必然线性无关。</span>

基解决了“**怎样表示候选函数**”。但还没回答：**怎样衡量两个候选谁离目标更近？**

::: exam [作业] HW2 问题 3：Chebyshev 多项式与单项式张成同一空间，且关于权 1/√(1 − x²) 正交
(1) 构造矩阵 $A \in \mathbb R^{(n+1)\times(n+1)}$，使 $A\,[1, x, \dots, x^n]^\top = [T_0(x), \dots, T_n(x)]^\top$（只需给出构造方法）；(2) 证明 $\operatorname{span}\{T_i\}_{i=0}^n = \operatorname{span}\{x^i\}_{i=0}^n$；(3) 证明 $\{T_i\}_{i\ge0}$ 在内积 $\langle f,g\rangle = \int_{-1}^1 \frac{f(x)g(x)}{\sqrt{1-x^2}}dx$ 下构成多项式的一组正交基。

**用到**：3.6.2 的三项递推、本节的三角换基矩阵；**思路方向**：(1) 用递推式逐行写出 $A$ 的第 $k+1$ 行与前两行的关系；(2) 看 $A$ 的形状和对角元；(3) 内积是课件没有讲的新内容（下一讲会讲正交），做变量替换 $x = \cos\theta$，看权函数 $\frac{1}{\sqrt{1-x^2}}$ 和 $dx$ 合起来变成什么，积分就化成 $[0,\pi]$ 上两个余弦乘积的积分。
:::

::: tldr
选定线性无关的基后，函数 ↔ 系数向量；$T_0,\dots,T_{n-1}$ 与 $1,\dots,x^{n-1}$ 之间差一个对角元非零的三角矩阵，张成同一个 $\mathcal P_{n-1}$。
:::

## 3.16 还缺一把“尺子”：范数

### 3.16.1 向量的范数 <Src p="26" />

要说两个向量谁更“接近”，需要先定义长度。对 $x = (x_1,\dots,x_n)^\top \in \mathbb R^n$：

$$
\|x\|_\infty = \max_i |x_i|,\qquad
\|x\|_2 = \Big(\sum_{i=1}^n x_i^2\Big)^{1/2},\qquad
\|x\|_1 = \sum_{i=1}^n |x_i|,\qquad
\|x\|_p = \Big(\sum_{i=1}^n |x_i|^p\Big)^{1/p} .
$$

<span class="muted">（注：课件此页未写 $p$ 的范围；$\|\cdot\|_p$ 只在 $p \ge 1$ 时是范数，P38 补充页写明了 $1 \le p < \infty$。$0 < p < 1$ 时三角不等式不成立，例如 $p = \tfrac12$，$x = (1,0)$、$y = (0,1)$：$\|x+y\|_{1/2} = 4 > 2 = \|x\|_{1/2} + \|y\|_{1/2}$。）</span>

<Fig src="/img/03/p026.jpg" size="md" cap="ℝ² 中的单位球：‖x‖₁ = 1 是菱形，‖x‖₂ = 1 是圆，‖x‖∞ = 1 是正方形" p="26" />

**同一个向量空间可以有不同的“长度”；范数就是衡量误差的一把尺子。**

<span class="muted">补充说明：课件没有写出范数的公理。向量空间 $V$ 上的**范数**<span class="en">Norm</span>是满足下面三条的函数 $\|\cdot\| : V \to \mathbb R$：(1) 正定性 $\|v\| \ge 0$，且 $\|v\| = 0 \iff v = 0$；(2) 齐次性 $\|cv\| = |c|\,\|v\|$；(3) 三角不等式 $\|u + v\| \le \|u\| + \|v\|$。上面的单位球都关于原点对称且是凸集，正对应齐次性和三角不等式。</span>

### 3.16.2 p-范数之间没有谁永远“更正确” <Src p="38" />

对 $x \in \mathbb R^n$，$1 \le p < \infty$，$\|x\|_p = \big(\sum_i |x_i|^p\big)^{1/p}$。有限维空间中所有范数在拓扑意义下等价（收敛与否不依赖选哪个范数），但**常数会依赖维数**。例如

$$
\|x\|_\infty \le \|x\|_2 \le \sqrt n\,\|x\|_\infty .
$$

算法里真正重要的不是“范数是否等价”，而是**误差界中的常数如何随维数增长**：$n = 10^6$ 时，两种范数下的误差界可以差 1000 倍。

<L03Norms />

::: exam [作业] HW3 问题 2(3)(4)：p-范数趋于 ∞-范数；‖x‖∞ ≤ ‖x‖₂ ≤ √n‖x‖∞
(3) 对 $x \in \mathbb R^n$，证明 $\lim_{p\to\infty}\|x\|_p = \|x\|_\infty = \max_i|x_i|$；(4) 证明 $\|x\|_\infty \le \|x\|_2 \le \sqrt n\,\|x\|_\infty$。

**用到**：本节的 $p$-范数定义和 P38 的范数比较；**思路方向**：(3) 把最大分量 $\|x\|_\infty$ 从求和号里提出来（和第 01 讲 1.3.2 防溢出时的缩放是同一个动作），括号里剩下的和介于哪两个与 $p$ 无关的数之间？再用夹逼。(4) 两边平方，分别把 $\sum x_i^2$ 与 $\max_i x_i^2$、$n\max_i x_i^2$ 比较；想想等号何时成立。
:::

### 3.16.3 函数的无穷范数与 2-范数 <Src p="27" />

对 $f : [a,b] \to \mathbb R$：

| 无穷范数（∞-norm） | 2-范数（$L^2$-norm） |
|---|---|
| $\displaystyle\|f\|_\infty = \sup_{x\in[a,b]} |f(x)|$ | $\displaystyle\|f\|_2 = \Big(\int_a^b |f(x)|^2\,dx\Big)^{1/2}$ |
| 只看最坏的那个点 | 衡量整个区间上的整体误差 |

<span class="muted">（注：课件写“对 $f : [a,b] \to \mathbb R$”，严格地说应限定在 $C[a,b]$ 这样的函数空间上：一般函数的 $\sup$ 可能为 $\infty$；而只在一个点非零的函数 $2$-范数为 0，正定性失效。对连续函数两者都是范数。）</span>

前半讲一直写的 $\max_x|f(x) - p(x)|$，现在可以记成 $\|f - p\|_\infty$；$E_{n-1}(f) = \min_{p\in\mathcal P_{n-1}}\|f - p\|_\infty$。**最佳 2-范数逼近通常比最佳无穷范数逼近容易计算**——下一讲会看到，它归结为解线性方程组。

先从最简单的离散版本开始：只看有限个样本点，把一串误差看成 $\mathbb R^m$ 中的向量。

::: tldr
范数是误差的尺子：$\infty$-范数看最坏点，$2$-范数看整体；有限维中各范数等价，但等价常数会随维数增长。
:::

## 3.17 离散最小二乘：让平方误差最小

### 3.17.1 选基 + 采样得到线性方程 <Src p="28" />

固定基 $\phi_1,\dots,\phi_n$，写 $p_c(x) = \sum_{j=1}^n c_j\phi_j(x)$。只在样本点 $t_1,\dots,t_m$ 上观察误差。令

$$
A_{ij} = \phi_j(t_i),\qquad b_i = f(t_i),\qquad\text{于是}\quad (Ac - b)_i = p_c(t_i) - f(t_i) .
$$

如果要求精确通过所有样本点，就必须解 $Ac = b$。**固定基后，未知量是系数 $c$；采样把函数值变成向量 $b$。**

::: qa 上面得到的线性方程 Ac = b 一定有解吗？ @P28
**不一定**。例如样本点比基函数多（$m > n$）而数据带噪声时，$b$ 一般不在 $A$ 的列空间里，精确拟合不可能完成；反过来样本点太少时又可能有无穷多组解。下一小节把所有情况说清楚。
:::

### 3.17.2 线性方程 Ac = b：只有三种可能 <Src p="29" />

从这里开始，$A$ 不必来自函数拟合：对任意 $A \in \mathbb R^{m\times n}$、$b \in \mathbb R^m$，线性方程 $Ac = b$ 只有三种可能：**无解**（inconsistent）、**唯一解**、**无穷多解**。

::: def 解集的结构 @P29
若 $c_0$ 是 $Ac = b$ 的一个解，则全部解恰好是
$$
c = c_0 + z,\qquad Az = 0 .
$$
特别地，若 $c_1 \ne c_2$ 都是解，那么 $c_1 + t(c_2 - c_1)$（$t \in \mathbb R$）也全都是解；因此不可能“恰好有两个解”。
:::

**证明**<span class="muted">（补充说明，课件只给结论）</span>：若 $Ac = b$，则 $A(c - c_0) = b - b = 0$，所以 $z := c - c_0$ 满足 $Az = 0$；反之若 $Az = 0$，则 $A(c_0 + z) = b + 0 = b$。对两个解 $c_1 \ne c_2$，$z = c_2 - c_1 \ne 0$ 满足 $Az = 0$，于是 $A(c_1 + tz) = b$ 对所有 $t$ 成立，且这些点两两不同——得到无穷多个解。所以有解时，要么零空间只有 $\{0\}$（唯一解），要么有无穷多解。$\blacksquare$

::: warn 方程个数 ≠ 解的个数 @P29
over-determined（方程多于未知量）/ under-determined（方程少于未知量）只描述方程数与未知量数的多少，**不等同于**“无解 / 无穷多解”。例如方程多于未知量也可能有唯一解（数据恰好相容），方程少于未知量也可能无解（两条方程互相矛盾）。
:::

若 $Ac = b$ 无解，精确拟合不可能完成。下一步：**既然不能让误差为零，就让误差尽可能小**。

### 3.17.3 最小二乘法 <Src p="30" />

::: def 最小二乘法（离散线性版本） @P30
当 $Ac = b$ 无解时，不再要求误差为零，而是求
$$
\min_c\ \|Ac - b\|_2^2 = \min_c \sum_{i=1}^{m} |p_c(t_i) - f(t_i)|^2 .
$$
这就是**最小二乘法**<span class="en">Least squares</span>。
:::

写 $A = [A_1\ \cdots\ A_n]$（按列），则 $Ac = c_1A_1 + \dots + c_nA_n$。因此所有可能的 $Ac$ 正好组成线性子空间

$$
V := \operatorname{span}\{A_1,\dots,A_n\}\quad(A \text{ 的列空间}).
$$

<Fig src="/img/03/p030.jpg" size="sm" cap="b 不一定在 V 中；最小二乘解 Ac* 是 V 中离 b 最近的向量" p="30" />

**最小二乘 = 在 $V$ 中找离 $b$ 最近的向量**（用 2-范数量距离）。这是离散平方误差；连续的 $L^2$ 逼近稍后会以同样的“最佳逼近”思想出现。

::: exam [作业] HW3 问题 4：Chebyshev 内积下 T_d 的最佳逼近
在内积 $\langle f,g\rangle = \int_{-1}^1 \frac{f(x)g(x)}{\sqrt{1-x^2}}dx$ 及其诱导范数 $\|f\| = \sqrt{\langle f,f\rangle}$ 下，对 $d > 1$，求 $a_0,\dots,a_{d-1}$ 使 $\|T_d - (a_0T_0 + \dots + a_{d-1}T_{d-1})\|$ 最小。

**用到**：本节“在子空间里找最近点”的观点（这里子空间是 $\operatorname{span}\{T_0,\dots,T_{d-1}\}$），以及 HW2 问题 3 证明的正交性（3.15 节的作业框）；**思路方向**：把要最小化的范数平方按内积双线性展开，利用正交性看哪些交叉项消失、剩下的部分关于 $a_k$ 什么时候最小。这道题用的内积与本讲的离散 2-范数不同，“最近点与正交”的一般原理下一讲才系统讲。
:::

::: tldr
选基 + 采样把拟合变成 $Ac = b$；它可能无解，于是改求 $\min\|Ac - b\|_2$，几何上就是在 $A$ 的列空间里找离 $b$ 最近的点。
:::

::: card 插值余项
- $f - P_f = \dfrac{f^{(n)}(\xi_x)}{n!}\,\omega_n(x)$，$\omega_n = \prod(x - x_j)$
- 证明：辅助多项式 $q = P_f + \lambda\omega_n$ + 反复 Rolle
- 最坏误差 $\sup_{\mathcal F_M} = \frac{M}{n!}\max\lvert\omega_n\rvert$（$f = Mx^n/n!$ 达到）
:::
::: card Chebyshev 多项式
- $T_n(\cos\theta) = \cos n\theta$，$T_{n+1} = 2xT_n - T_{n-1}$
- 首项系数 $2^{n-1}$，$\widehat T_n = 2^{1-n}T_n$ 首一
- 零点 $\cos\frac{(2i-1)\pi}{2n}$；极值点 $\cos\frac{k\pi}{n}$ 上 $T_n = (-1)^k$
:::
::: card 极小极大定理
- 首一 $n$ 次 $p$：$\max_{[-1,1]}\lvert p\rvert \ge 2^{1-n}$，$\widehat T_n$ 取等
- 证书：$n+1$ 个交替极值点 ⇒ 差有 $n$ 个零点，但次数 $\le n-1$
- 最优节点误差 $\frac{M}{n!}2^{1-n}$；$[a,b]$ 上乘 $\left(\frac{b-a}{2}\right)^n$
:::
::: card 逼近
- Bernstein：$B_nf = \mathbb E f(X/n)$，一致收敛、不过样本点
- $\|f - I_nf\|_\infty \le (1 + \Lambda_n)E_{n-1}(f)$
- $\Lambda_n$：Chebyshev $O(\log n)$，等距指数增长
:::
::: card 函数空间与范数
- 函数是向量；选线性无关的基 ⇒ 函数 ↔ 系数
- $T_0..T_{n-1}$ 与 $1..x^{n-1}$：三角换基，同一个 $\mathcal P_{n-1}$
- $\|x\|_\infty \le \|x\|_2 \le \sqrt n\|x\|_\infty$；$p \ge 1$ 才是范数
:::
::: card 最小二乘
- $Ac = b$：无解 / 唯一解 / 无穷多解，解集 $= c_0 + \ker A$
- $\min_c\|Ac - b\|_2^2$ = 在列空间中找离 $b$ 最近的点
- 下一讲：正交、Gram–Schmidt、QR
:::
