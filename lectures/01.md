## 1.2 这门课研究什么 <Src p="11" />

计算方法并不仅仅是一些“工程小技巧”。作为一门学科，它反复研究这些主题：

- **收敛性**：随着计算资源或近似层次增加，结果是否逼近目标；
- **复杂性**：达到给定精度要花多少次查询、多少次运算；
- **条件性（鲁棒性）**：问题本身对扰动有多敏感；
- **压缩性**、**正交性**……

误差与偏差，也不仅仅来源于浮点数或离散化处理——建模本身就是近似。

## 1.3 浮点数：先猜一猜

```cpp
double x = 0.3 * 3 + 0.1;
double y = 1.0;
if (x == y) cout << "Equal";
else cout << "Not equal";
```

::: qa 上面这段 C++ 程序会输出什么？（数学上 0.3 × 3 + 0.1 = 1） @P4–5
输出 **Not equal**（常见 IEEE 754 binary64 实现）。一种常见的双精度计算结果是 $x \approx 0.9999999999999999$。<Src p="A7" />

数学公式上的准确，在有限精度计算中未必准确。
:::

::: qa 那以后统一检查 |x − y| < ε 就够了吗？ε 应该多大？ @A7
**也不够**。同一个 $\varepsilon$ 对 $10^{-12}$ 和 $10^{12}$ 的意义完全不同：对前者 $\varepsilon = 10^{-10}$ 太宽松，对后者连相邻两个双精度数的间距都比它大。该用多大的 $\varepsilon$，取决于数据的**尺度**——这就是下一节要讲的相对误差。
:::

### 1.3.1 浮点数的理想化模型 <Src p="A11" />

在没有溢出 / 下溢等异常情形时，对基本运算 $\circ \in \{+,-,\times,/\}$，常用的理想化模型是

$$
\mathrm{fl}(a \circ b) = (a \circ b)(1+\delta), \qquad |\delta| \le u .
$$

- **好消息**：每一步的相对舍入误差通常很小，双精度浮点数的单位舍入 $u \approx 10^{-16}$（准确值 $2^{-53} \approx 1.1\times10^{-16}$）。
- **坏消息**：很多个很小的误差，经过病态的问题或不稳定的算法，可以变成很大的答案误差。

本课不做完整的浮点误差分析，而是先学习比 IEEE 754 更普遍的稳定性语言（条件数、前向 / 后向误差）。

### 1.3.2 两个典型问题 <Src p="6" />

**数值范围：溢出 / 下溢**。直接计算 $\|x\|_2 = \sqrt{\sum_i x_i^2}$，可能在平方时就超出可表示范围。先令 $m = \max_i |x_i|$ 再算

$$
\|x\|_2 = m\sqrt{\sum_i (x_i/m)^2},
$$

可以显著降低风险——每个 $x_i/m$ 都在 $[-1,1]$ 里，平方不会溢出。

**长计算：舍入误差累积**。反复求和时，“就近取整”与“截断”两种舍入方式下，误差的偏向与累积方式并不相同。**Kahan 补偿求和**把每一步被舍掉的低位存起来、下一步再加回去；Python 3.12 起内置 `sum()` 也改进了浮点求和精度。

::: prin 同一个数学量，可以有数值上完全不同的计算方式 @P6
William Kahan 是 IEEE 754 标准的重要奠基者，获得 1989 年图灵奖。<Src p="A11" />
:::

## 1.4 数值事故与稳定化技巧

### 1.4.1 Softmax 平移技巧 <Src p="7" />

$$
\mathrm{softmax}(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}} .
$$

若 $z = (1000, 999, 998)$，在双精度中直接形成 $e^{1000}$ 会溢出，后面的归一化甚至可能得到 NaN。<Src p="A13" /> 令 $m = \max_j z_j$，整体平移不改变 softmax（分子分母同乘 $e^{-m}$）：

$$
\mathrm{softmax}(z)_i = \frac{e^{z_i - m}}{\sum_j e^{z_j - m}} .
$$

数学上完全等价，数值范围却从 1000 附近变成 $0,-1,-2$。同一个技巧给出稳定的 log-sum-exp：

$$
\log \sum_j e^{z_j} = m + \log \sum_j e^{z_j - m}.
$$

同一种思路还会出现在：范数计算先缩放（1.3.2）、补偿求和、稳定的二次公式。

### 1.4.2 37 秒：Ariane 5 <Src p="8" />

1996 年 Ariane 501 首飞：起飞后飞行最初正常，约 36.7 s 惯性参考系统失效，约 37 s 丢失制导信息。<Src p="A12" />

Ariane 5 沿用了 Ariane 4 惯性参考系统中的旧软件。一个与水平速度相关的量超出了原设计假设的范围；把 64 位浮点数转换为 16 位有符号整数时触发异常，主、备两套惯性参考系统随后都失效。

::: warn 真正的教训 @P8
在 Ariane 4 上没出错，不代表这个假设是正确的——一个假设在旧系统里“从未出错”，并不会因此变成定理。数值范围、软件假设、异常处理、输入域和测试覆盖面，都是计算正确性的一部分。
:::

另一个经典案例是 Patriot 防空导弹的时间累积误差。<span class="muted">来源：ESA/CNES, Ariane 501 Inquiry Board Report (1996)。</span>

## 1.5 误差的度量

### 1.5.1 绝对误差与相对误差 <Src p="A8" />

设真实值为 $x$，计算结果为 $\hat x$。

::: def 绝对误差与相对误差 @A8
- **绝对误差**<span class="en">Absolute error</span>：$E_{\text{abs}} = |\hat x - x|$。直接度量偏差有多大，但数值大小依赖问题的单位和尺度。
- **相对误差**<span class="en">Relative error</span>：$E_{\text{rel}} = \dfrac{|\hat x - x|}{|x|}$（$x \ne 0$）。把误差除以答案本身的尺度，更适合比较不同量级的问题。
:::

::: ex 差一个“尺度” @A8
- $x = 10^{-8}$，$\hat x = 2\times10^{-8}$：$E_{\text{abs}} = 10^{-8}$ 很小，但 $E_{\text{rel}} = 1$，相对误差 100%。
- $x = 10^{8}$，$\hat x = 10^{8}+1$：$E_{\text{abs}} = 1$ 看似不小，但 $E_{\text{rel}} = 10^{-8}$，相对精度很好。

当真值接近 0 时，相对误差本身也可能不是合适的尺度。
:::

### 1.5.2 前向误差与残差：测量对象不同 <Src p="A9" />

“绝对 / 相对”说明**如何归一化**误差；“前向误差 / 残差”说明误差**测量的是哪个对象**。以求根为例，设真根为 $r$、近似解为 $x$：

- **根的前向误差**：$|x - r| \le \varepsilon$，计算出的根在**水平方向**离真根有多远；
- **残差**<span class="en">Residual</span>：$|f(x)| \le \varepsilon$，把近似解代回方程后，在**函数值方向**偏离零多少。

<Fig src="/img/01/a009.jpg" size="md" cap="小残差不一定意味着小前向误差：左图根附近斜率较大，右图斜率较小" p="A9" />

小残差不一定意味着小前向误差，关键在根附近的斜率（1.9 节会精确化）。

### 1.5.3 误差从哪里来：三层分开 <Src p="A10" />

| 层次 | 来源 | 示意 | 要问的问题 |
|---|---|---|---|
| 问题 / 数据<span class="en">Problem / data</span> | 测量、建模、输入扰动 | $x \to x + \Delta x$ | 问题本身会不会放大扰动？ |
| 算法<span class="en">Algorithm</span> | 截断、停止、近似子问题 | $y \to \hat y$ | 算法是否保留已有精度？ |
| 机器<span class="en">Machine</span> | 有限精度与舍入 | $z \to \mathrm{fl}(z)$ | 单步误差如何累积？ |

**条件性 ≠ 算法稳定性 ≠ 舍入误差**。本课程会反复问：误差从哪一层进入？经过计算后被放大多少？

::: tldr
先分清误差怎么归一化（绝对 / 相对）、量的是什么（前向误差 / 残差）、从哪一层来（问题 / 算法 / 机器），再谈放大。
:::

## 1.6 条件数：问题本身有多敏感

### 1.6.1 输入扰动如何传播到输出 <Src p="13" />

无论扰动来自测量、建模还是计算，先看最基本的一维问题：输入从 $x$ 变成 $x+\Delta x$，由局部线性化

$$
f(x+\Delta x) - f(x) \approx \Delta x\, f'(x).
$$

中值定理给出严格版本：若 $f \in C^1$，则存在 $\xi$ 位于 $x$ 与 $x+\Delta x$ 之间，使得

$$
f(x+\Delta x) - f(x) = \Delta x\, f'(\xi).
$$

**绝对误差的放大**<Src p="14" />：输入与输出的绝对误差分别是 $|\Delta x|$ 和 $|\Delta f| = |f(x+\Delta x) - f(x)|$，于是

$$
\frac{|\Delta f|}{|\Delta x|} \approx |f'(x)| .
$$

$|f'(x)| > 1$ 时误差被放大，$|f'(x)| < 1$ 时被收缩。但比较 $|f'(x)|$ 与 1 依赖所选尺度 / 单位（把 $x$ 从米换成毫米，$f'$ 就变了），这正是引入相对误差的原因。

### 1.6.2 相对条件数 <Src p="15" />

::: def 条件数 Condition number @P15
对标量映射 $y = f(x)$（$x \ne 0$，$f(x) \ne 0$），由局部线性化

$$
\frac{|\Delta y|}{|y|} \approx \underbrace{\left|\frac{x f'(x)}{f(x)}\right|}_{\kappa_f(x)} \frac{|\Delta x|}{|x|},
\qquad
\operatorname{cond}_f(x) = \kappa_f(x) := \left|\frac{x f'(x)}{f(x)}\right| .
$$

条件数是**相对误差的局部放大倍数**。它无量纲，简单的单位换算不改变它。<Src p="A16" />
:::

- **怎么读**：$\kappa \ll 1$，扰动被压缩；$\kappa \gg 1$，扰动被放大（问题**病态**）。
- **三秒例子**：$f(x) = x^p$ 时 $\kappa_f(x) = \left|\dfrac{x \cdot p x^{p-1}}{x^p}\right| = |p|$——平方使相对误差约翻倍，开平方使它约减半。<Src p="A16" />

::: qa 如果 f 不可导，或 f′(x) 难以直接控制呢？ @P15
那就退回到定义本身：直接估计 $\dfrac{|f(x+\Delta x)-f(x)|/|f(x)|}{|\Delta x|/|x|}$ 在小扰动下的上确界。课件留作思考，后面讲到向量和矩阵时会用范数推广这个定义（算子范数与矩阵条件数）。<span class="muted">（补充说明）</span>
:::

### 1.6.3 局部线性化：今天真正的主角 <Src p="A18" />

一个可微函数在局部看起来像线性函数：

$$
f(x+h) = f(x) + f'(x)h + O(h^2).
$$

| 用来分析 | 用来设计算法 |
|---|---|
| 输入误差 $h$ ⟹ 输出误差 $\approx f'(x)h$ | 把 $f$ 换成切线 ⟹ 解一个简单的线性问题 |

**条件数与牛顿法，其实来自同一个泰勒展开。**

::: tldr
条件数 $\kappa_f(x) = |x f'(x)/f(x)|$ 是问题的属性：它说明输入的相对误差会被放大多少倍，与用什么算法无关。
:::

## 1.7 前向误差、后向误差与稳定性 <Src p="16" />

算法输出 $\hat y$。若它可以解释成某个**附近输入**的精确答案 $\hat y = f(\tilde x)$，就可以在相对尺度下比较两种误差：

::: def 前向误差与后向误差 @A14
- **前向误差**<span class="en">Forward error</span>：$\dfrac{|\hat y - f(x)|}{|f(x)|}$，输出 $\hat y$ 离真解 $f(x)$ 多远；
- **后向误差**<span class="en">Backward error</span>：$\dfrac{|\tilde x - x|}{|x|}$，最少需要把输入改动多少，才能让 $\hat y = f(\tilde x)$。

**后向稳定** ≈ “精确地解决了一个几乎相同的问题”。
:::

<Fig src="/img/01/a014.jpg" size="md" cap="前向误差看输出端，后向误差把算法误差“推回”输入端" p="A14" />

| 问题条件性<span class="en">Problem conditioning</span> | 算法稳定性<span class="en">Algorithmic stability</span> |
|---|---|
| 输入扰动 $\Delta x$ ⟹ 真解变化 $\Delta y$，$\dfrac{\lvert\Delta y\rvert}{\lvert y\rvert} \approx \kappa \dfrac{\lvert\Delta x\rvert}{\lvert x\rvert}$ | 计算得到 $\hat y$，能否解释为 $\hat y = f(x+\Delta x)$、$\lvert\Delta x\rvert$ 很小？ |
| 这是**问题**的属性 | 这是**算法**的属性 |

::: prin 前向误差 ≲ 条件数 × 后向误差 @A17
推导：$\hat y = f(\tilde x)$，把 $\tilde x$ 看作 $x$ 的扰动输入，代入条件数的定义即得

$$
\frac{|\hat y - f(x)|}{|f(x)|} = \frac{|f(\tilde x) - f(x)|}{|f(x)|} \approx \kappa_f(x)\,\frac{|\tilde x - x|}{|x|}.
$$

这是局部 / 一阶的关系，两边要用相容的误差尺度。**病态问题限制任何算法；不稳定算法则会浪费本来可以保留的精度。**
:::

### 1.7.1 在算法之前：先检查问题是否适定 <Src p="A15" />

Hadamard 的经典问题意识可以翻译成三个问题（记 $Z(f) = \{x : f(x) = 0\}$）：

| 存在性 Existence | 唯一性 / 目标 Uniqueness | 稳定性 Stability |
|---|---|---|
| 解存在吗？$Z(f) \ne \varnothing$？ | 解唯一吗？$\lvert Z(f)\rvert = 1$？若不唯一，输出目标是否明确？ | 输入稍变，解是否稍变？$\Delta f \Rightarrow \Delta r$？ |
| 没有解，算法无从谈起 | 多解也可以算，但目标必须说清楚 | 连续依赖才允许可靠计算 |

数值分析从选择算法之前就已经开始。先问：**有解？目标明确？稳定？**

::: tldr
前向误差 ≲ 条件数 × 后向误差：结果差，要么是问题病态（换算法也没用），要么是算法不稳定（换算法就有用）。
:::

## 1.8 一个算法问题需要完整的定义

先从一个一维模型问题入手，把收敛、复杂性、条件性真正算一遍。<Src p="21" />

::: def 求根问题 @P21
- **输入**：连续函数 $f$，并承诺它至少有一个根；
- **求解**：任意一个 $r$，使得 $f(r) = 0$；
- **神谕（预言机）模型**：$f$ 以黑盒给定，可以查询任意 $f(x)$；稍后再允许查询 $f'(x)$。<Src p="A5" />
:::

<Fig src="/img/01/a005.jpg" size="sm" cap="给定 f，求 r 使得 f(r) = 0" p="A5" />

一个完整的算法问题由四部分组成 <Src p="A5" /><Src p="A21" />：

$$
\text{find } \hat r \ \ \text{s.t.}\ \ \operatorname{dist}\big(\hat r, Z(f)\big) \le \varepsilon,\qquad Z(f) = \{x : f(x)=0\}.
$$

| 承诺 Promise | 信息 Oracle | 精度 Accuracy | 代价 Cost |
|---|---|---|---|
| 连续？单调？光滑？给了区间？ | 只有符号？$f(x)$？$f'(x)$？更高阶？ | $\lvert\hat r - r\rvert$？相对误差？残差？概率？ | 查询次数？算术运算？精度所需的比特数？内存？ |

**Promise + Information + Accuracy + Cost 才组成一个算法问题**。今天会看到两种极端：二分法全局可靠，牛顿法局部极快。它们的差别来自信息、结构和局部几何，而不只是公式不同。<Src p="A5" />

::: qa 为什么需要假设 f 连续？ @P21
不连续时，“承诺至少有一个根”也帮不上忙：函数值可以在某点直接从负跳到正而不经过 0，异号区间里未必有根，介值定理失效；即使真有根，它也可以藏在任意窄的一个点上，有限次查询根本碰不到。下面的对手思维实验把这个直觉说清楚。<span class="muted">（补充说明）</span>
:::

### 1.8.1 为什么需要结构假设：一个对手思维实验 <Src p="A22" />

设算法只查询了有限多个点 $x_1,\dots,x_T$，而每次都得到同一个回答 $f(x_i) = 1$，最后只能给出同一个输出 $\hat r$。但同一份查询记录背后可以是两个不同的实例：一个的根在 $z_1$，另一个的根在 $z_2$，$|z_1 - z_2| > 2\varepsilon$（在查询点之间挖一个窄坑即可）。算法不可能对两者都做到 $|\hat r - r| \le \varepsilon$。

<Fig src="/img/01/a022.jpg" size="md" cap="同样的查询结果，根却可以在 z₁ 或 z₂" p="A22" />

::: prin 结构假设 = 信息 @A22
结构假设排除了与已知数据不可区分的坏实例。连续性 + 异号区间，就是二分法需要的那一点结构。
:::

::: tldr
求根问题 = 承诺 + 信息 + 精度 + 代价；没有结构假设，有限次查询无法给出任何保证。
:::

## 1.9 根的条件性：从残差到位置误差

### 1.9.1 一阶分析 <Src p="A19" />

设 $f(r) = 0$，而我们只能把方程满足到一个小残差尺度 $\eta$：$f(r+\Delta r) = \eta$。在**简单根** $r$（$f'(r) \ne 0$）附近做一阶展开：

$$
\eta = f(r+\Delta r) \approx f(r) + f'(r)\Delta r = f'(r)\Delta r
\quad\Longrightarrow\quad
\Delta r \approx \frac{\eta}{f'(r)},\qquad \kappa^{\text{abs}}_{\text{root}}(r) \approx \frac{1}{|f'(r)|}.
$$

- **陡峭穿越**<span class="en">Steep crossing</span>：$|f'(r)|$ 大，小残差通常意味着小根误差；
- **平缓穿越**<span class="en">Flat crossing</span>：$|f'(r)|$ 小，同样的残差可能对应很大的位置误差。

<Fig src="/img/01/a020.jpg" cap="同样的 η = 0.3，根的位移正好按 1/|f′(r)| 放大：陡的 |Δr| = 0.5，平的 |Δr| = 2" p="A20" />

残差是可观测的；前向误差是否小，取决于条件性。

<L01RootCond />

### 1.9.2 函数本身有误差：对扰动参数求导 <Src p="33–34" />

设 $r$ 是 $f$ 的简单根。假设计算函数本身有误差，记误差函数为 $\varepsilon h(x)$，实际求根的是

$$
\tilde f_\varepsilon(x) = f(x) + \varepsilon h(x).
$$

把附近的扰动根记为 $r(\varepsilon) = r + \Delta r$，于是恒等式 $f(r(\varepsilon)) + \varepsilon h(r(\varepsilon)) = 0$ 对所有小 $\varepsilon$ 成立。**一个小的函数误差，会让根移动多少？**

对这个恒等式在 $\varepsilon = 0$ 处求导（链式法则，并用 $r(0) = r$）：

$$
f'(r)\,r'(0) + h(r) = 0
\quad\Longrightarrow\quad
r'(0) = -\frac{h(r)}{f'(r)} .
$$

隐函数定理可以严格化“扰动根随参数可微”这一步（条件正是 $f'(r) \ne 0$）。因此

$$
r(\varepsilon) = r - \varepsilon\frac{h(r)}{f'(r)} + o(\varepsilon).
$$

::: warn 简单根越“平”，根越敏感 @P34
局部尺度 $\sim 1/|f'(r)|$，与 1.9.1 是同一个结论。重根 $f'(r) = 0$ 时一阶近似失效（1.21 节会看到 $|\Delta r|$ 变成 $\eta^{1/m}$）。
:::

::: exam [作业] HW1 问题 2：Wilkinson 多项式的根有多敏感
(1) 证明 $\left.\dfrac{dx}{d\varepsilon}\right|_{\varepsilon=0} = -\dfrac{p(x^*)}{f'(x^*)}$；(2) 对 $f(x) = (x-1)(x-2)\cdots(x-20)$、扰动 $p(x) = x^{19}$（只有 $a_{19}$ 有误差），证明根 $x^* = j$ 处的导数是 $-\prod_{k\ne j} \dfrac{j}{j-k}$；(3) 比较 $x^*=1$ 与 $x^*=20$ 哪个更稳定。

**用到**：本节的隐函数求导推导（第 1 问就是它，把 $h$ 换成 $p$）；**思路方向**：第 2 问对乘积形式的 $f$ 求 $f'(j)$ 时，只有不含 $(x-j)$ 的那一项在 $x=j$ 处不为 0；第 3 问直接比较两个乘积的数量级。
:::

::: tldr
根的绝对条件数约为 $1/|f'(r)|$：函数值上的误差 $\eta$（不管来自残差还是函数本身的扰动）会让根移动约 $\eta/|f'(r)|$。
:::

## 1.10 二分法：用拓扑信息换取全局保证

::: def 介值定理与异号区间 @P22
若 $f$ 连续且 $f(a)f(b) < 0$，则 $[a,b]$ 内至少有一个根 $r$。称这样的 $[a,b]$ 为**异号区间**。
:::

<Fig src="/img/01/a023.jpg" size="md" cap="每一步只问一个问题：根在哪一半？" p="A23" />

### 1.10.1 算法：不变量 + 不确定性收缩 <Src p="23" />

<Fig src="/img/01/a024.jpg" size="md" cap="当前区间 [a_k, b_k]，查询中点 m_k，保留左半或右半" p="A24" />

**一次迭代**：
1. 查询中点 $m_k = (a_k + b_k)/2$；
2. 检查 $f(m_k)$ 的符号；
3. 保留仍然异号的那一半区间。

- **不变量**<span class="en">Invariant</span>：$f(a_k)f(b_k) \le 0$。由连续性（介值定理），区间内始终至少夹着一个根。
- **进展**<span class="en">Progress</span>：$L_{k+1} = \frac12 L_k$，其中 $L_k = b_k - a_k$。每次查询都把不确定区间恰好缩短一半。

### 1.10.2 收敛速度：一行复杂度分析 <Src p="24" />

初始区间长度 $L_0 = b - a$，$k$ 次二分后 $L_k = \dfrac{b-a}{2^k}$。输出中点 $x_k$，则某个被夹住的根 $r$ 满足

$$
|x_k - r| \le \frac{L_k}{2} = \frac{b-a}{2^{k+1}} .
$$

要达到 $|x_k - r| \le \varepsilon$，只需 $\dfrac{b-a}{2^{k+1}} \le \varepsilon$，即

$$
k \ge \left\lceil \log_2 \frac{b-a}{2\varepsilon} \right\rceil ,
$$

也就是 $O\!\left(\log \dfrac{b-a}{\varepsilon}\right)$ 次迭代。

::: prin 一个值得记住的算法学规律 @A25
每一步把不确定性缩小一个常数因子 $\rho < 1$，通常意味着达到精度 $\varepsilon$ 需要 $O(\log(1/\varepsilon))$ 步。
:::

## 1.11 二分法在单比特预言机中已经最优 <Src p="A26" />

甚至只考虑最简单的函数族 $f_r(x) = x - r$，未知 $r \in [a,b]$。令预言机每次只返回一个比特：

$$
Q_r(x) = \mathbf 1[r \le x],
$$

也就是带固定规则处理相等情形的符号 / 阈值查询。

::: def 定理（二分法下界） @A26
在单比特预言机模型中，任何（可以自适应选择查询点的）确定性算法要保证 $|\hat r - r| \le \varepsilon$，都需要 $k = \Omega\!\left(\log \dfrac{b-a}{\varepsilon}\right)$ 次查询。
:::

**证明**（课件给出框架，这里补全每一步）<span class="muted">（补充说明）</span>

1. **决策树**：算法第 $i$ 次查询哪个点，只能依赖前 $i-1$ 次的回答。所以 $k$ 次查询的整个过程可以画成一棵深度为 $k$ 的二叉树：每个内部结点是一次查询，左右分支对应回答 0 / 1。一份**查询记录**（$k$ 个比特）对应一片叶子，而算法的输出 $\hat r$ 只由叶子决定。叶子至多 $2^k$ 片，所以算法至多给出 $2^k$ 种不同输出。
2. **要区分多少种答案**：在 $[a,b]$ 中取等距的候选根 $r_1 < r_2 < \dots < r_N$，相邻间距略大于 $2\varepsilon$，可取 $N = \Theta\!\left(\dfrac{b-a}{\varepsilon}\right)$ 个，且两两距离 $> 2\varepsilon$。
3. **鸽巢原理**：若 $2^k < N$，必有两个候选根 $r_i \ne r_j$ 走到同一片叶子，得到同一个输出 $\hat r$。由三角不等式 $|r_i - r_j| \le |r_i - \hat r| + |\hat r - r_j|$，而左边 $> 2\varepsilon$，所以两项中至少有一项 $> \varepsilon$——算法在其中一个实例上失败。
4. 因此必须 $2^k \ge N$，即 $k \ge \log_2 N = \Omega\!\left(\log \dfrac{b-a}{\varepsilon}\right)$。$\blacksquare$

二分法的上界 $\lceil\log_2\frac{b-a}{2\varepsilon}\rceil$ 与这个下界同阶，所以**二分法在这个模型中已最优**；要更快，必须利用更丰富的局部信息（函数值大小、导数）。

其实这就是连续版的“猜数字 / 20 Questions”：每问一次，只得到 left / right 一个比特。

::: tldr
二分法每步用 1 个比特把区间减半，$O(\log\frac{b-a}{\varepsilon})$ 步；在只给符号的模型里这已经是最优的。
:::

## 1.12 从求根到不动点：方程 ≠ 算法

二分法维护一个**区间**；另一条路线是只维护一个**当前猜测** $x_k$。<Src p="25" /> 把 $f(x) = 0$ 改写成等价的不动点方程 $g(x) = x$，然后直接迭代

$$
x_{k+1} = g(x_k), \qquad k = 0,1,2,\dots
$$

::: def 不动点与不动点迭代 @P26
若 $g(r) = r$，称 $r$ 为 $g$ 的一个**不动点**<span class="en">Fixed point</span>。从初值 $x_0$ 出发做上面的迭代，称为**不动点迭代**。
:::

这样可以利用函数的局部形状，但失去了二分法“根始终被夹住”的自动保证。**怎样选择 $g$，让根成为稳定的不动点？**

::: ex 同一个方程，完全不同的动力学 @P26
- **坏改写**：$x = 0$ 等价于 $x = 2x$。迭代 $x_{k+1} = 2x_k$ 给出 $x_k = 2^k x_0$，若 $x_0 \ne 0$ 就发散。<Src p="26" />
- **以 $x^2 = 2$ 为例** <Src p="A27" />：
  - 合法但糟糕的改写 $g_1(x) = 2/x$：从 $x_0 = 1$ 得到 $1 \to 2 \to 1 \to 2 \to \cdots$，而且 $g_1'(\sqrt2) = -2/(\sqrt 2)^2 = -1$；
  - 精心设计的改写 $g_2(x) = \frac12\left(x + \frac2x\right)$：从 $x_0 = 1$ 得到 $1 \to 1.5 \to 1.4167 \to \cdots$，而且 $g_2'(\sqrt 2) = \frac12\left(1 - \frac{2}{2}\right) = 0$。

**选择更新映射 $g$，本身就是算法设计。**
:::

::: def 命题：如果迭代收敛，极限一定是不动点 @P27
若 $x_{k+1} = g(x_k)$，$g$ 连续，而且 $x_k \to r$，则 $g(r) = r$。
:::

**证明**：利用 $g$ 的连续性把极限移进去：

$$
g(r) = g\Big(\lim_{k\to\infty} x_k\Big) \overset{\text{连续}}{=} \lim_{k\to\infty} g(x_k) \overset{\text{迭代式}}{=} \lim_{k\to\infty} x_{k+1} = r. \qquad\blacksquare
$$

## 1.13 Cobweb 图：一次迭代到底在做什么 <Src p="28" />

在同一张图上画 $y = g(x)$ 和 $y = x$。从 $x_0$ 开始：**竖直**走到 $y = g(x)$ 得到 $x_1 = g(x_0)$；再**水平**走到 $y = x$，把 $g(x_0)$ 重新解释为下一次的输入 $x_1$；如此反复得到 $x_2 = g(x_1), \dots$

## 1.14 局部收敛与稳定性

### 1.14.1 收敛速度的定义 <Src p="29" />

记第 $k$ 次迭代误差 $e_k = |x_k - r|$。若极限

$$
S = \lim_{k\to\infty} \frac{e_{k+1}}{e_k}
$$

存在，称 $S$ 为**收敛速度**。$0 < S < 1$ 称为**线性收敛**；$S = 0$ 比线性收敛更快（后面牛顿法会出现）。<span class="muted">（注：课件没有讨论 $S = 1$ 的情形，这时称为次线性收敛，比任何线性收敛都慢。）</span>

### 1.14.2 第一步只需要中值定理 <Src p="30" />

设 $g$ 连续可导，$g(r) = r$。由中值定理，

$$
x_{k+1} - r = g(x_k) - g(r) = g'(\xi_k)(x_k - r),
$$

其中 $\xi_k$ 位于 $x_k$ 与 $r$ 之间。因此 $e_{k+1} = |g'(\xi_k)|\, e_k$。

### 1.14.3 什么时候会收敛 <Src p="31" />

::: def 定理（局部收敛） @P31
设 $g \in C^1$，$g(r) = r$，$\rho := |g'(r)| < 1$。则存在 $r$ 的邻域，只要 $x_0$ 在其中，就有 $x_k \to r$，并且
$$
S = \lim_{k\to\infty}\frac{e_{k+1}}{e_k} = |g'(r)| = \rho .
$$
$0 < \rho < 1$ 时线性收敛；$\rho = 0$ 时可能更快。
:::

**证明**（每步注明依据）：

1. 取 $q = \dfrac{1+\rho}{2}$，因为 $\rho < 1$，有 $\rho < q < 1$。
2. **由 $g'$ 连续**：$|g'(x)| \to \rho < q$（$x \to r$），所以存在 $\delta > 0$，在邻域 $I = [r-\delta, r+\delta]$ 上 $|g'(x)| \le q$。
3. **归纳**：若 $x_k \in I$，则 $\xi_k$（介于 $x_k$ 与 $r$ 之间）也在 $I$ 里，由 1.14.2 得 $e_{k+1} = |g'(\xi_k)|e_k \le q e_k \le e_k \le \delta$，所以 $x_{k+1} \in I$。从 $x_0 \in I$ 出发，所有迭代点都留在 $I$ 内，且 $e_{k+1} \le q e_k$。
4. 于是 $e_k \le q^k e_0 \to 0$，即 $x_k \to r$。
5. 因为 $\xi_k$ 夹在 $x_k$ 与 $r$ 之间，$\xi_k \to r$；再由 $g'$ 连续，$\dfrac{e_{k+1}}{e_k} = |g'(\xi_k)| \to |g'(r)| = \rho$（这里假设 $x_k \ne r$，否则已经精确命中）。$\blacksquare$

### 1.14.4 稳定与不稳定的不动点 <Src p="32" />

| 稳定的不动点 | 不稳定的不动点 |
|---|---|
| 附近迭代趋向 $r$；误差越来越小 | 附近迭代远离 $r$；小扰动会被放大 |
| $\lvert g'(r)\rvert < 1$，误差被局部**压缩** | $\lvert g'(r)\rvert > 1$，误差被局部**放大**；与“混沌”现象相关 |

例如 $g_\lambda(x) = x - \lambda f(x)$（$\lambda \ne 0$）的不动点正是 $f$ 的根，而 $g_\lambda'(r) = 1 - \lambda f'(r)$。**选择更新规则，就是在选择局部收缩率**：取 $\lambda = 1/f'(r)$ 就能让 $g_\lambda'(r) = 0$——但 $f'(r)$ 事先不知道，牛顿法的做法是每一步用 $1/f'(x_k)$ 代替。

## 1.15 压缩映射：把局部直觉变成全局保证 <Src p="A30" />

::: def 压缩映射定理（一维版本） @A30
若 $g : [a,b] \to [a,b]$，且存在 $q < 1$ 使得对所有 $x, y \in [a,b]$
$$
|g(x) - g(y)| \le q|x-y|,
$$
则 $g$ 存在**唯一**不动点 $r$，且从任意 $x_0 \in [a,b]$ 出发，$|x_k - r| \le q^k |x_0 - r|$。
:::

**一维里怎么检查**：若 $\sup_{x\in[a,b]} |g'(x)| \le q < 1$，中值定理直接给出压缩性：$|g(x)-g(y)| = |g'(\xi)||x-y| \le q|x-y|$。

**证明**（课件说“反复迭代即可，唯一性也只需一行”，这里写完整）：

- **存在性**<span class="muted">（补充说明，课件未写）</span>：压缩映射是连续的。令 $\phi(x) = g(x) - x$，由于 $g$ 把 $[a,b]$ 映进自身，$\phi(a) = g(a) - a \ge 0$，$\phi(b) = g(b) - b \le 0$。由介值定理，存在 $r \in [a,b]$ 使 $\phi(r) = 0$，即 $g(r) = r$。（又一次用到二分法背后的那个定理。）
- **收敛**：$|x_{k+1} - r| = |g(x_k) - g(r)| \le q|x_k - r|$，即 $|e_{k+1}| \le q|e_k|$；反复迭代得 $|x_k - r| \le q^k|x_0 - r| \to 0$。
- **唯一性**：若 $r, r'$ 都是不动点，则 $|r - r'| = |g(r) - g(r')| \le q|r - r'|$，因 $q < 1$ 只能 $|r-r'| = 0$。$\blacksquare$

与 1.14.3 的区别：1.14.3 只保证“$x_0$ 足够近”时收敛；压缩映射定理在**整个区间**上给出保证，代价是要验证 $g$ 把区间映进自身、且处处压缩。

::: exam [作业] HW1 问题 3：两个映射混合迭代仍然指数压缩
设 $f_0(x) = \frac{1}{2+x}$，$f_1(x) = \frac{1}{3+x}$，按任意 0/1 串 $\sigma$ 依次复合得到 $g^T_\sigma = f_{\sigma(T)}\circ\cdots\circ f_{\sigma(1)}$。证明存在绝对常数 $C > 0$，对所有 $\sigma$、$T \ge 3$ 和 $x_1, x_2 \ge 0$ 都有 $|g^T_\sigma(x_1) - g^T_\sigma(x_2)| \le e^{-CT}|x_1 - x_2|$。

**用到**：本节“导数上界 ⇒ 压缩”的检查方法；**思路方向**：先确认每个 $f_i$ 把 $\mathbb R_{\ge0}$ 映进哪个区间，再在该区间上给 $|f_i'|$ 找一个与 $i$ 无关的上界，复合时用链式法则或逐层套用中值定理。
:::

## 1.16 如何比较“收敛得有多快” <Src p="A31" />

::: def 收敛阶 @A31
设 $e_k = |x_k - r| \to 0$。若对某个 $p \ge 1$，
$$
\lim_{k\to\infty}\frac{e_{k+1}}{e_k^{\,p}} = C,\qquad 0 < C < \infty
$$
（当 $p = 1$ 时还要求 $C < 1$），则称收敛阶为 $p$。
:::

| $p$ | 名称 | 计算上的含义 |
|---|---|---|
| 1 | 线性 linear | 误差每步乘一个固定因子 $C < 1$ |
| $> 1$ | 超线性 superlinear | 越接近，误差缩得越快 |
| 2 | 二次 quadratic | 正确位数大约每步翻倍 |

由 1.14.3，一般不动点迭代的收敛阶是 1，比例常数是 $|g'(r)|$。**能不能设计一个不动点映射 $g$，让 $g'(r) = 0$？**

::: tldr
不动点迭代的局部行为由 $|g'(r)|$ 决定：小于 1 收敛且线性，大于 1 发散；把 $g'(r)$ 设计成 0，就能突破线性收敛。
:::

## 1.17 牛顿法：在当前位置把世界“线性化” <Src p="35" />

在 $x_k$ 处，用切线（一阶局部模型）近似 $f$：

$$
f(x) \approx f(x_k) + f'(x_k)(x - x_k).
$$

不直接解难方程 $f(x) = 0$，而是先解这个线性近似：令它等于 0，

$$
0 = f(x_k) + f'(x_k)(x_{k+1} - x_k)
\quad\Longrightarrow\quad
\boxed{\,x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}\,}.
$$

<Fig src="/img/01/a033.jpg" size="md" cap="牛顿步的几何图像：x_{k+1} 是切线与横轴的交点" p="A33" />

**局部近似 → 精确求解局部模型 → 重复迭代**。切线不是“画图技巧”，它是一阶局部模型。<Src p="A33" />

同一个 $1/f'$：在 1.9 节它控制根的敏感性，在这里它决定牛顿修正的尺度。<Src p="35" />

::: exam [作业] HW2 问题 1：Newton–Raphson 除法
(1) 只用至多两次乘法、一次加减法（不用除法），写出用牛顿法计算 $1/a$ 的迭代；(2) 记 $\varepsilon_k := a x_k - 1$，证明 $\varepsilon_{k+1} = -\varepsilon_k^2$；(3) 要把结果精确到 $1/2^d$ 大约要迭代几次（用 $\varepsilon_0$ 和 $d$ 表示，设 $|\varepsilon_0| < 1$）；(4) 是否对任意初值都收敛？

**用到**：本节的牛顿迭代公式，1.20 节“误差平方 ⇒ $\log\log$ 步数”；**思路方向**：关键是选一个根为 $1/a$、但牛顿步里不出现除法的 $f$（例如 $f(x) = 1/x - a$）；第 4 问从 $\varepsilon_{k+1} = -\varepsilon_k^2$ 看 $|\varepsilon_0|$ 落在什么范围时会收敛、什么范围会爆掉。

## 1.18 牛顿法是“精心设计”的不动点迭代 <Src p="37" />

牛顿法就是不动点迭代 $x_{k+1} = g(x_k)$，其中

$$
g(x) = x - \frac{f(x)}{f'(x)} .
$$

简单根 $r$ 满足 $f(r) = 0$，因此 $g(r) = r$。更关键的是它的导数。由商的求导法则：

$$
g'(x) = 1 - \frac{f'(x)f'(x) - f(x)f''(x)}{f'(x)^2} = \frac{f(x)f''(x)}{f'(x)^2},
\qquad\text{所以}\quad g'(r) = \frac{0\cdot f''(r)}{f'(r)^2} = 0 .
$$

::: prin 设计原则 @A34
普通不动点迭代的一阶误差项是 $g'(r)e_k$，即 $e_{k+1} \approx |g'(r)|e_k$。牛顿法选择 $g$，使这个一阶项**在根处自动消失**；误差展开从二阶或更高阶开始。
:::

::: exam [作业] HW1 问题 4：g′(r) = 0 ⇒ 二次收敛
设 $g$ 二次可导，$g(r) = r$，$g'(r) = 0$，$|g''(r)| < 2$，且 $g''$ 在 $r$ 的一个邻域里连续。证明 $x_{k+1} = g(x_k)$ 在 $r$ 的一个邻域上二次收敛。

**用到**：本节“$g'(r)=0$ 消掉一阶项”的观察，和 1.19 节泰勒展开 + 1.14.3 “先找邻域、再归纳留在邻域内”的证明模板；**思路方向**：把 $g(x_k)$ 在 $r$ 处展开到带拉格朗日余项的二阶，想想条件 $|g''(r)| < 2$ 在“迭代点不跑出邻域”那一步起什么作用。
:::

## 1.19 牛顿法的局部二次收敛

::: def 定理（局部二次收敛） @P36
设 $f \in C^2$，$f(r) = 0$ 且 $f'(r) \ne 0$。若 $x_0$ 足够接近 $r$，牛顿迭代定义良好并收敛到 $r$，而且当 $k$ 足够大时 $|e_{k+1}| \le C|e_k|^2$（$e_k = x_k - r$）。更精确地，
$$
\lim_{k\to\infty}\frac{|e_{k+1}|}{|e_k|^2} = \left|\frac{f''(r)}{2f'(r)}\right| .
$$
若 $f''(r) \ne 0$，精确收敛阶为 2；若 $f''(r) = 0$，可能比二次收敛更快。<Src p="A35" />
:::

误差被“平方”：$e \to e^2 \to e^4 \to e^8$，正确位数通常每步约翻倍，有时更快。机制：一阶项被消掉，二阶余项主导。

### 1.19.1 证明只需要一次泰勒展开 <Src p="38" />

**第 1 步：误差递推**。在 $x_k$ 附近对根 $r$ 做带拉格朗日余项的泰勒展开：存在 $\xi_k$ 位于 $x_k$ 与 $r$ 之间，使

$$
0 = f(r) = f(x_k) + f'(x_k)(r - x_k) + \tfrac12 f''(\xi_k)(r - x_k)^2 .
$$

牛顿步满足 $f(x_k) + f'(x_k)(x_{k+1} - x_k) = 0$。两式相减消去 $f(x_k)$：

$$
f'(x_k)(r - x_{k+1}) + \tfrac12 f''(\xi_k)(r-x_k)^2 = 0
\quad\Longrightarrow\quad
x_{k+1} - r = \frac{f''(\xi_k)}{2f'(x_k)}(x_k - r)^2 ,
$$

即

$$
|e_{k+1}| = \left|\frac{f''(\xi_k)}{2f'(x_k)}\right| |e_k|^2 .
$$

牛顿步恰好消掉泰勒展开的常数项和一阶项，只留下二阶余项。<Src p="A36" />

**第 2 步：为什么“足够接近”就一定收敛**<span class="muted">（补充说明，课件只写了“$x_0$ 足够接近”）</span>。因为 $f'(r) \ne 0$ 且 $f', f''$ 连续，可以取 $\delta > 0$ 使在 $I = [r-\delta, r+\delta]$ 上 $|f'(x)| \ge m > 0$、$|f''(x)| \le M$；再缩小 $\delta$ 使 $\dfrac{M}{2m}\delta \le \dfrac12$。若 $x_k \in I$，则 $\xi_k \in I$，第 1 步给出

$$
|e_{k+1}| \le \frac{M}{2m}|e_k|^2 \le \frac{M}{2m}\delta\,|e_k| \le \tfrac12|e_k| ,
$$

所以 $x_{k+1}$ 仍在 $I$ 内（迭代定义良好，因为 $f'(x_{k+1}) \ne 0$），且 $|e_k| \le 2^{-k}|e_0| \to 0$。

**第 3 步：极限常数**。$x_k \to r$ 推出 $\xi_k \to r$，由 $f', f''$ 连续，$\left|\dfrac{f''(\xi_k)}{2f'(x_k)}\right| \to \left|\dfrac{f''(r)}{2f'(r)}\right|$。$\blacksquare$

## 1.20 二次收敛：把收敛速度翻译成复杂度 <Src p="A37" />

一旦进入局部收敛域，把常数吸收到误差尺度里，可粗略看成 $e_{k+1} \lesssim e_k^2$。于是经过 $t$ 步，误差的**指数**反复翻倍：

$$
10^{-2} \to 10^{-4} \to 10^{-8} \to 10^{-16},\qquad e_{k+t} \text{ 大致为 } e_k^{2^t}.
$$

::: def 迭代复杂度 @A37
固定一个已经进入收敛域的起点，要达到 $e \le \varepsilon$，局部只需
$$
t = O\!\left(\log\log\frac1\varepsilon\right)
$$
次牛顿迭代。（由 $e_k^{2^t} \le \varepsilon$ 得 $2^t \ge \frac{\log(1/\varepsilon)}{\log(1/e_k)}$，再取一次对数。）
:::

::: qa 这为什么不违反 1.11 节二分法的下界？ @A37
二分法的下界只允许**单比特符号**信息；牛顿法使用 $f$ 和 $f'$ 的数值（更丰富的信息），而且这里只是**局部**保证（要先进入收敛域）。两个结论的前提不同，并不矛盾。
:::

### 1.20.1 例子：√2、巴比伦开方法与牛顿法 <Src p="A38" />

求 $f(x) = x^2 - 2$ 的根：

$$
x_{k+1} = x_k - \frac{x_k^2 - 2}{2x_k} = \frac12\left(x_k + \frac{2}{x_k}\right).
$$

这正是 1.12 节的 $g_2$，也就是巴比伦 / Heron 开平方迭代。从 $x_0 = 1$ 开始：

| $k$ | $x_k$ | $\lvert x_k - \sqrt2\rvert$ |
|---|---|---|
| 0 | 1 | $4.14\times10^{-1}$ |
| 1 | 1.5 | $8.58\times10^{-2}$ |
| 2 | 1.4166666667 | $2.45\times10^{-3}$ |
| 3 | 1.4142156863 | $2.12\times10^{-6}$ |
| 4 | 1.4142135624 | $\approx 1.6\times10^{-12}$ |

检验定理的常数：$\left|\dfrac{f''(r)}{2f'(r)}\right| = \dfrac{2}{2\cdot 2\sqrt2} = \dfrac{1}{2\sqrt2} \approx 0.354$；表中 $\dfrac{2.12\times10^{-6}}{(2.45\times10^{-3})^2} \approx 0.353$，吻合。<span class="muted">（补充说明）</span>

## 1.21 牛顿法的局限

### 1.21.1 牛顿法很快，但它不是“无条件正确” <Src p="A39" />

考虑 $f(x) = x^3 - 2x + 2$，$f'(x) = 3x^2 - 2$。从 $x_0 = 0$：

$$
x_1 = 0 - \frac{2}{-2} = 1,\qquad x_2 = 1 - \frac{1}{1} = 0,\qquad 0 \leftrightarrow 1 \leftrightarrow 0 \leftrightarrow \cdots
$$

牛顿法进入了 **2-周期**，根一个也没找到（实根在 $r \approx -1.769$）。

::: warn 局部收敛的真正含义 @A39
牛顿法的二次收敛定理只承诺：**当你已经足够接近一个简单根时**，它会极快收敛。离根远时，它可能循环、发散，或跳到别的根。
:::

### 1.21.2 重根：算法变慢，问题本身也变脆弱 <Src p="A40" />

若 $f(x) = (x-r)^m$，$m > 1$，则 $f'(x) = m(x-r)^{m-1}$，牛顿更新直接化成

$$
x_{k+1} = x_k - \frac{(x_k - r)^m}{m(x_k-r)^{m-1}} = r + \left(1 - \frac1m\right)(x_k - r),
\qquad e_{k+1} = \left(1 - \frac1m\right)e_k .
$$

- **动力学**：$g'(r) = 1 - 1/m \ne 0$，从二次收敛降成**线性收敛**。
- **条件性**：例如对 $\eta > 0$，微小的常数扰动 $(x-r)^m = \eta$ 会产生尺度 $|\Delta r| = \eta^{1/m}$ 的根位移，远大于 $\eta$（$\eta = 10^{-12}$、$m = 3$ 时 $|\Delta r| = 10^{-4}$）。

**同一个退化 $f'(r) = 0$，同时破坏条件性与牛顿迭代的动力学**。因此：算法收敛快不等于问题条件良好；两件事必须分别分析。

::: ex [补充] 已知重数 m 时怎样修改更新式 @A46
课后练习 3 的答案方向：把牛顿步乘以 $m$，$x_{k+1} = x_k - m\dfrac{f(x_k)}{f'(x_k)}$。对 $f = (x-r)^m$ 代入得 $x_{k+1} = x_k - (x_k - r) = r$，一步命中；对一般的 $m$ 重根，修正后 $g'(r) = 0$，恢复二次收敛。在上面的牛顿法演示里选“三重根”并勾选修正即可看到。<span class="muted">（补充说明）</span>
:::

## 1.22 实用求根器与牛顿法的推广

### 1.22.1 还能利用什么信息 <Src p="39" />

- 牛顿法每一步只需要函数值和一阶导数；二次收敛分析甚至可以只要求 $f'$ 局部利普希茨连续；
- 使用更高阶导数，可以做更高阶的局部近似（例如 Halley 方法，三阶收敛）；
- 牛顿法很自然地推广到多变量求根和最优化（1.22.4）。

### 1.22.2 导数不容易求：割线法 <Src p="40" />

**割线法**<span class="en">Secant method</span>用最近两次的函数值近似导数：

$$
x_{k+1} = x_k - f(x_k)\,\frac{x_k - x_{k-1}}{f(x_k) - f(x_{k-1})} .
$$

在简单根和常规光滑条件下，其收敛阶为 $\dfrac{1+\sqrt5}{2} \approx 1.618$。<span class="muted">（补充说明：类似 1.19.1 的分析给出 $e_{k+1} \approx C e_k e_{k-1}$；设 $e_{k+1} \sim e_k^p$，代入得 $p = 1 + 1/p$，即 $p^2 = p + 1$。）</span>每步只要一次新的函数值，按“每次函数求值”算，它常常比牛顿法更划算。

高维中也有类似思想：Broyden 方法用于非线性方程组；BFGS 是最经典的优化拟牛顿方法之一。

### 1.22.3 现实中的求根器：全局保证 + 局部加速 <Src p="41" />

| 二分法 / 异号区间 | 快速局部步（牛顿 / 割线 / 逆二次插值） |
|---|---|
| 保持异号区间，保证根不丢 | 接近根时很快 |
| 稳健但较慢 | 单独使用不够稳健 |

<Fig src="/img/01/a041.jpg" size="sm" cap="先维护区间 → 尝试牛顿步 / 割线步 → 步子不安全就退回二分" p="A41" />

**全局可靠性 + 局部高速**。Dekker / Brent 等求根方法正是这种设计哲学：维持异号区间，同时尝试更快的插值步。

### 1.22.4 同一个模板：标量 → 向量 → 优化 <Src p="A42" />

<Fig src="/img/01/a042.jpg" size="sm" cap="导数 → 雅可比矩阵 → Hessian" p="A42" />

| 问题 | 方程 | 牛顿步 |
|---|---|---|
| 标量求根 | $f(x) = 0$ | $f'(x_k)\Delta_k = -f(x_k)$ |
| 向量求根 | $F(x) = 0$ | $J_F(x_k)\Delta_k = -F(x_k)$ |

## 1.23 不动点远不止求根 <Src p="42" />

::: def Brouwer 不动点定理 @P42
连续映射 $F : K \to K$，其中 $K \subset \mathbb R^d$ 非空、紧致、凸，则 $F$ 有不动点。
:::

- **Sperner 引理**：Brouwer 定理的组合对应物；也可以用来证明 Brouwer；
- Sperner 型论证 ⟶ **公平分租**问题；
- Brouwer / Kakutani ⟶ **纳什均衡**<span class="en">Nash equilibrium</span>的存在性。

一维情形其实就是 1.15 节存在性证明里用的介值定理论证：$g : [a,b] \to [a,b]$ 连续即有不动点。<span class="muted">（补充说明）</span>

::: tldr
牛顿法 = 每步解一次切线模型；$g'(r) = 0$ 让它在简单根附近二次收敛，但它只是局部的：离根远会失效，重根会退化成线性。实践中用“区间保护 + 快速局部步”兼顾两头。
:::

### 1.24.1 一分钟检查 <Src p="A44" />

::: qa 为什么残差很小，仍可能离真实根很远？哪一个量控制这种放大？
根附近斜率小时，同样的纵向残差对应很大的横向位移：$|\Delta r| \approx \eta/|f'(r)|$，控制放大的是根的条件数 $1/|f'(r)|$（1.9 节）。
:::

::: qa 条件性与算法稳定性分别属于“问题”还是“算法”？
条件性属于**问题**（与用什么算法无关）；稳定性属于**算法**。两者通过“前向误差 ≲ 条件数 × 后向误差”连起来（1.7 节）。
:::

::: qa 为什么二分法需要 Θ(log((b − a)/ε)) 次符号查询，而且这个量级无法改进？
上界：每次区间减半。下界：$k$ 次单比特查询至多 $2^k$ 种输出，却要区分 $\Theta((b-a)/\varepsilon)$ 个两两相距 $> 2\varepsilon$ 的候选根（1.11 节）。
:::

::: qa 同一个方程为什么可以有收敛、发散、周期等完全不同的不动点迭代？
因为迭代的局部行为由 $|g'(r)|$ 决定，而同一个方程可以改写成许多不同的 $g$：$x^2=2$ 时 $g_1 = 2/x$ 给出 $|g_1'(r)| = 1$（周期），$g_2$ 给出 $g_2'(r) = 0$（极快收敛）（1.12–1.14 节）。
:::

::: qa 牛顿法为什么在简单根附近至少二次收敛？一句话解释，不要背证明。
牛顿法精确解掉局部一阶模型，所以误差只从二阶余项开始。<Src p="A44" />
:::

### 1.24.3 下节课：从“局部线性”到“全局多项式” <Src p="A45" />

## ★ 本讲速记

:::: recap
::: card 误差的语言
- 绝对误差 $\lvert\hat x - x\rvert$ / 相对误差 $\lvert\hat x - x\rvert/\lvert x\rvert$
- 前向误差（输出端）/ 残差（代回方程）/ 后向误差（推回输入端）
- 浮点模型 $\mathrm{fl}(a\circ b) = (a\circ b)(1+\delta)$，$\lvert\delta\rvert \le u \approx 10^{-16}$
:::
::: card 条件数
- $\kappa_f(x) = \lvert x f'(x)/f(x)\rvert$，问题的属性
- 前向误差 ≲ 条件数 × 后向误差
- 根的绝对条件数 $\approx 1/\lvert f'(r)\rvert$；重根时 $\lvert\Delta r\rvert \sim \eta^{1/m}$
:::
::: card 二分法
- 不变量 $f(a_k)f(b_k) \le 0$，每步区间减半
- $k \ge \lceil\log_2\frac{b-a}{2\varepsilon}\rceil$ 步
- 单比特预言机下界 $\Omega(\log\frac{b-a}{\varepsilon})$：二分法最优
:::
::: card 不动点迭代
- 收敛则极限是不动点（需 $g$ 连续）
- $e_{k+1} = \lvert g'(\xi_k)\rvert e_k$；$\lvert g'(r)\rvert < 1$ 局部线性收敛，速度 $\lvert g'(r)\rvert$
- 压缩映射：$g([a,b]) \subset [a,b]$ 且 $\sup\lvert g'\rvert \le q < 1$ ⇒ 唯一不动点、全局收敛
:::
::: card 牛顿法
- $x_{k+1} = x_k - f(x_k)/f'(x_k)$，$g'(r) = 0$
- $\lvert e_{k+1}\rvert = \left\lvert\frac{f''(\xi_k)}{2f'(x_k)}\right\rvert e_k^2$，极限常数 $\left\lvert\frac{f''(r)}{2f'(r)}\right\rvert$
- 局部 $O(\log\log\frac1\varepsilon)$ 步
:::
::: card 牛顿法的边界
- 只保证局部：$x^3-2x+2$ 从 0 出发 2-周期
- $m$ 重根退化为线性，$e_{k+1} = (1-\frac1m)e_k$；修正：乘 $m$
- 割线法阶 1.618；实践用 Brent：区间保护 + 快速步
:::
