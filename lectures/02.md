# 插值、秘密分享与纠错码

<p class="lead">只看到有限个观察值，怎样恢复完整的对象？这一讲先把“精确重建”讲透：次数小于 n 的多项式由 n 个取值唯一决定（拉格朗日插值）。同一个事实换一种用法——故意少给几个值，就得到 Shamir 秘密分享；故意多给几个值，就得到能纠错的 Reed–Solomon 码。最后回到实数：节点上完全正确，并不意味着节点之间逼近得好（Runge 现象）。</p>

### 2.2.1 精确重建与数值逼近：两件不同的事 <Src p="7" />

| | 精确重建<span class="en">Algebraic reconstruction</span> | 数值逼近<span class="en">Numerical approximation</span> |
|---|---|---|
| 假设 | 未知对象**真的就是** $p \in \mathcal P_{<n}$（次数 $< n$ 的多项式） | 真实函数 $f$ 未必是多项式，用 $P$ 去近似它，$P(x_i) = f(x_i)$ |
| 问题 | 有限个取值能否**唯一决定** $p$？ | 在采样点**之间**，$P$ 与 $f$ 相差多大？ |
| 性质 | 代数问题：不需要连续性，甚至可以在有限域上讨论 | 连续性只能排除跳变；要得到定量误差界，还需要导数有界或更高阶的光滑性 |

本讲先把精确重建讲清楚（PART 1–3）；最后再回到数值逼近（PART 4），那时才真正需要讨论误差与光滑性。

### 2.2.2 为什么多项式同时适合这两个问题？ <Src p="8" />

**作为精确模型：有限维，代数结构清楚**。$p(x) = a_0 + a_1x + \cdots + a_nx^n$：

- $n+1$ 个系数 = $n+1$ 个自由度；
- 加、乘、求导、积分都封闭且易算；
- 在复数域中可以分解为 $p(x) = a_n \prod_{i=1}^n (x - r_i)$（代数基本定理），实系数时非实根成共轭对出现。

**作为逼近模型：表达能力强**。

- 泰勒展开<span class="en">Taylor expansion</span>给出局部多项式近似；
- **Weierstrass 逼近定理**：闭区间上的连续函数可以被多项式任意一致逼近（2.23 节给出一个构造性证明）；
- 电路和神经网络当然也可以用来表示函数；多项式则是最容易分析的起点。

::: warn 注意 @P8
Weierstrass 只保证“好的逼近多项式**存在**”，并**不保证**任意节点上的高次插值会收敛（2.21 节的 Runge 现象就是反例）。
:::

::: tldr
有限个点决定不了一个任意函数；先把模型限定为“次数 < n 的多项式”，才能谈唯一恢复。精确重建是代数问题，数值逼近才需要光滑性。
:::

## 2.3 同一个多项式，两套坐标 <Src p="9" />

次数 $< n$ 的多项式构成一个 $n$ 维线性空间 $\mathcal P_{<n}$。同一个 $p$ 有两套坐标：

| 系数坐标 | | 取值坐标 |
|---|---|---|
| $\mathbf a = (a_0,\dots,a_{n-1})$，$p(x) = \sum_{j=0}^{n-1} a_j x^j$ | $\Longleftrightarrow$ | $\mathbf y = (y_1,\dots,y_n)$，$y_i = p(x_i)$，$x_i$ 两两不同 |

使用单项式基 $1, x, \dots, x^{n-1}$ 时，这个坐标变换就是一个 **Vandermonde 线性方程组**：

$$
\mathbf y = V\mathbf a,\qquad V_{ij} = x_i^{\,j-1},\qquad y_i = \sum_{j=0}^{n-1} a_j x_i^{\,j}.
$$

<span class="muted">（注：课件这里 $V$ 的列下标从 1 开始、系数下标从 0 开始，所以 $V$ 的第 $j$ 列乘的是 $a_{j-1}$。）</span>

所谓“插值”，就是已知取值坐标 $\mathbf y$、求系数坐标 $\mathbf a$——换坐标。**拉格朗日插值**的思路是：直接选一组与“取值”这个操作相适应的基，不必先求出单项式系数。

## 2.4 拉格朗日插值：存在且唯一 <Src p="10–13" />

::: def 定理（拉格朗日插值） @P10
给定 $n$ 个横坐标互不相同的数据点 $(x_1, y_1), \dots, (x_n, y_n)$，存在**唯一**一个次数至多 $n-1$ 的多项式 $P$，满足
$$
P(x_i) = y_i,\qquad i = 1,\dots,n.
$$
:::

先构造存在性，再证明唯一性。

### 2.4.1 存在性：拉格朗日基函数 <Src p="11–12" />

想找 $L_k$ 使得 $L_k(x_k) = 1$，$L_k(x_j) = 0$（$j \ne k$）。先让它在其他节点自动为零：$L_k(x) = A_k \prod_{j\ne k}(x - x_j)$；再选常数 $A_k$ 使 $L_k(x_k) = 1$，即 $A_k = 1/\prod_{j\ne k}(x_k - x_j)$（节点互不相同，分母非零）。归一化得到

$$
\boxed{\,L_k(x) = \prod_{j\ne k} \frac{x - x_j}{x_k - x_j}\,}
$$

它是 $n-1$ 个一次因子的乘积，次数恰为 $n-1$。

<Fig src="/img/02/p011.jpg" size="sm" cap="例：节点 −1, 0, 1 时，L₂(x) = 1 − x²" p="11" />

例如节点 $x_1, x_2, x_3 = -1, 0, 1$ 时，$L_2(x) = \dfrac{(x+1)(x-1)}{(0+1)(0-1)} = 1 - x^2$。

这些基函数正是取值坐标的“单位向量”：因为 $L_k(x_i) = \mathbf 1\{i = k\}$，令

$$
P(x) = \sum_{k=1}^n y_k L_k(x),
$$

就有 $P(x_i) = \sum_k y_k L_k(x_i) = y_i$。$P$ 是 $n$ 个次数 $\le n-1$ 的多项式的线性组合，次数 $\le n-1$。存在性得证。

### 2.4.2 唯一性：n 个点已经用完所有自由度 <Src p="13" />

假设 $P, Q$ 次数都至多 $n-1$，而且都通过给定的 $n$ 个点。令 $H(x) = P(x) - Q(x)$，则 $H$ 次数至多 $n-1$，且 $H(x_1) = \cdots = H(x_n) = 0$。但一个**非零**的次数至多 $n-1$ 的多项式最多有 $n-1$ 个不同的根，因此 $H \equiv 0$，即 $P \equiv Q$。$\blacksquare$

这一步用到的“根的个数”引理是全讲的基石（后面纠错码的距离也靠它），这里补上证明。

::: prin 引理：非零的 d 次多项式至多有 d 个不同的根 @P13
对任意**域**（实数、复数、有限域 $\mathbb F_q$ 都可以）上的多项式成立。<span class="muted">（补充说明，课件直接使用）</span>
:::

**证明**（对次数 $d$ 归纳）：
1. $d = 0$：非零常数没有根。
2. **因式定理**：若 $p(r) = 0$，用 $x - r$ 做带余除法 $p(x) = (x-r)s(x) + c$，余数 $c$ 是常数（除式是一次的）；代入 $x = r$ 得 $c = p(r) = 0$，所以 $p(x) = (x-r)s(x)$，$\deg s = d - 1$，且 $s \ne 0$。
3. 若 $p$ 有 $d+1$ 个不同的根 $r, r_1, \dots, r_d$：对每个 $r_i \ne r$，$0 = p(r_i) = (r_i - r)s(r_i)$，而 $r_i - r \ne 0$ 在域中可逆，所以 $s(r_i) = 0$。于是 $s$ 有 $d$ 个不同的根，与归纳假设（$s$ 至多 $d-1$ 个根）矛盾。$\blacksquare$

（第 3 步用到“非零元可逆、没有零因子”，这正是为什么后面要在**域**上做。）

**推论**：节点两两不同时，Vandermonde 矩阵 $V$ 可逆。因为 $V\mathbf a = \mathbf 0$ 意味着多项式 $\sum a_j x^j$ 在 $n$ 个不同点上为零，次数 $< n$，由引理只能 $\mathbf a = \mathbf 0$。“存在且唯一”就是“这个线性坐标变换是双射”。<span class="muted">（补充说明）</span>

### 2.4.3 一分钟练习：什么时候次数会更低？ <Src p="14–15" />

::: qa 用拉格朗日插值找出通过 (1, 1)、(2, 1) 的次数至多 1 的多项式。 @P14–15
$$
L_1(x) = \frac{x-2}{1-2} = 2 - x,\qquad L_2(x) = \frac{x-1}{2-1} = x - 1,
$$
因此 $P(x) = 1\cdot L_1(x) + 1\cdot L_2(x) = 1$。

**“次数至多 $n-1$”并不意味着实际次数一定达到 $n-1$**。两个点的纵坐标相同，插值多项式就退化成常数。
:::

::: tldr
$L_k = \prod_{j\ne k}\frac{x-x_j}{x_k-x_j}$ 在第 $k$ 个节点取 1、其余节点取 0；$P = \sum y_k L_k$ 给出存在性，“非零 $d$ 次多项式至多 $d$ 个根”给出唯一性。
:::

## 2.5 公式写出来以后，表示仍然重要 <Src p="16" />

直接用 $P(x) = \sum_{k=1}^n y_k L_k(x)$ 在一个新点求值：每个 $L_k(x)$ 含 $O(n)$ 个因子，朴素实现需要 $O(n^2)$ 次算术运算。

| 表示方式 | 构造或预处理 | 之后单点求值 |
|---|---|---|
| 直接拉格朗日公式 | — | $O(n^2)$ |
| 牛顿差商形式 | $O(n^2)$ | $O(n)$ |
| 拉格朗日重心形式 | $O(n^2)$ | $O(n)$ |

**同一个数学对象，换一种表示，就可能得到不同的计算复杂性与数值行为**。

课件只列出了表格，下面补充两种形式是什么。<span class="muted">（补充说明）</span>

**牛顿差商形式**。换一组“逐个加节点”的基 $1,\ (x-x_1),\ (x-x_1)(x-x_2),\ \dots$：

$$
P(x) = c_0 + c_1(x - x_1) + c_2(x-x_1)(x-x_2) + \cdots + c_{n-1}\prod_{j=1}^{n-1}(x - x_j).
$$

依次代入 $x_1, x_2, \dots$ 解出的系数是**差商**：$c_j = f[x_1,\dots,x_{j+1}]$，递推定义为 $f[x_i] = y_i$，

$$
f[x_i,\dots,x_{i+j}] = \frac{f[x_{i+1},\dots,x_{i+j}] - f[x_i,\dots,x_{i+j-1}]}{x_{i+j} - x_i}.
$$

差商表一共 $O(n^2)$ 项，每项 $O(1)$；之后用嵌套乘法（类似 Horner）$P(x) = c_0 + (x-x_1)\big(c_1 + (x-x_2)(c_2 + \cdots)\big)$ 求值只要 $O(n)$。好处还有：新增一个节点时，前面的系数都不变，只需再算一列差商。

**重心形式**。令 $\omega(x) = \prod_{j}(x - x_j)$，**重心权** $w_k = 1/\prod_{j\ne k}(x_k - x_j)$（预处理 $O(n^2)$）。则 $L_k(x) = \omega(x)\dfrac{w_k}{x - x_k}$。对常数函数 1 插值得到 $1 = \sum_k L_k(x) = \omega(x)\sum_k \frac{w_k}{x - x_k}$，两式相除消去 $\omega(x)$：

$$
P(x) = \frac{\displaystyle\sum_{k} \frac{w_k}{x - x_k}\, y_k}{\displaystyle\sum_{k} \frac{w_k}{x - x_k}}\qquad (x \ne x_k),
$$

每次求值 $O(n)$，而且数值上很稳定。本讲的 Runge 演示（2.21 节）就用它计算。

## 2.7 11 位科学家与 462 把锁 <Src p="18" />

11 位科学家希望保护一个高度机密的档案：**当且仅当至少 6 人在场，才能打开档案**。如果只用普通锁和钥匙：

$$
\binom{11}{5} = 462 \text{ 把锁},\qquad \text{每人需要 } \binom{10}{5} = 252 \text{ 把钥匙}.
$$

为什么是这两个数？<span class="muted">（补充说明）</span>

- **构造**：为每个 5 人小组 $S$ 配一把锁，钥匙发给 $S$ 之外的 6 个人。任何 5 人小组 $S$ 都打不开“自己那把锁”；任何 6 人小组，对每把锁 $S$ 都至少有一人不在 $S$ 里，从而有钥匙。锁共 $\binom{11}{5} = 462$ 把；某人拿到的钥匙对应不含他的 5 人小组，共 $\binom{10}{5} = 252$ 把。
- **不能更少**：每个 5 人小组 $S$ 必须被某把锁挡住（$S$ 中没人有这把锁的钥匙）。若两个不同的 5 人小组 $S \ne S'$ 被同一把锁挡住，则 $S \cup S'$（至少 6 人）里也没人有这把钥匙，打不开——矛盾。所以至少要 462 把不同的锁。

人数继续增加时，这种组合构造会迅速爆炸。**Shamir（1979）：用一个 5 次多项式代替几百把锁**。

## 2.8 有限域上的多项式 <Src p="19" />

为简单起见，先取 $q$ 为素数，$\mathbb F_q = \mathbb Z/q\mathbb Z$。加、减、乘、除都在模 $q$ 的意义下进行（除数非零）：

$$
p(x) = a_0 + a_1 x + \cdots + a_k x^k,\qquad a_i,\ x \in \mathbb F_q .
$$

| 系数表示 | 取值表示 |
|---|---|
| $(a_0, \dots, a_k)$ | $\big(p(x_0), \dots, p(x_k)\big)$ |

只要横坐标互不相同，次数 $\le k$ 的多项式仍由 $k+1$ 个点唯一决定。

为什么 2.4 节的证明在 $\mathbb F_q$ 上照样成立？拉格朗日公式只用到加减乘和“除以非零元 $x_k - x_j$”；根的个数引理只用到“非零元可逆”。$q$ 是素数时，每个非零的 $a \bmod q$ 都有逆元（扩展欧几里得算法求出 $ua + vq = 1$，则 $u$ 就是逆元），所以 $\mathbb Z/q\mathbb Z$ 是域。<span class="muted">（补充说明）</span>

::: prin 有限域上的“错误”不是舍入误差 @P19
有限域上的算术本身是**精确**的；后面所说的“错误”来自通信或存储过程中符号发生改变，而不是浮点舍入误差。
:::

## 2.9 Shamir 秘密分享 <Src p="20–21" />

::: def Shamir 秘密分享（6-out-of-11） @P20
在有限域 $\mathbb F_q$ 中，令秘密为 $s \in \mathbb F_q$，**均匀随机**选择 $a_1, \dots, a_5 \in \mathbb F_q$，定义
$$
p(x) = s + a_1 x + \cdots + a_5 x^5 .
$$
第 $i$ 个人得到一份份额 $\big(x_i,\ p(x_i)\big)$，其中 $x_i \ne 0$，且所有 $x_i$ 互不相同。
:::

<span class="muted">（注：要给 11 人分配互不相同的非零 $x_i$，需要 $q \ge 12$；课件没写出这个条件。实际中 $q$ 取得远大于人数，也要大于秘密可能的取值范围。）</span>

**恢复**：任意 6 人拿到 6 个点，由 2.4 节，次数 $\le 5$ 的多项式被唯一确定，用拉格朗日插值恢复 $p$，进而得到 $s = p(0)$。其实只需算一个值：$s = P(0) = \sum_k y_k L_k(0) = \sum_k y_k \prod_{j\ne k}\frac{x_j}{x_j - x_k}$。

### 2.9.1 少于 6 份：为什么秘密仍然完全隐藏？ <Src p="21" />

已经看到的 5 份份额 $(x_1, y_1), \dots, (x_5, y_5)$ 固定不动。任取一个候选秘密 $s' \in \mathbb F_q$，加入第 6 个点 $(0, s')$。这 6 个点横坐标互不相同（因为 $x_i \ne 0$），唯一确定一个次数至多 5 的多项式 $p_{s'}(x)$。所以对**每一个** $s'$，都**恰好有一组** $(a_1, \dots, a_5)$ 与已经看到的份额相容。

由于随机系数 $(a_1,\dots,a_5)$ 是均匀选择的，**无论真实秘密取什么值，这 5 份份额的联合分布都完全一样**。

把最后一句写成概率等式（补全课件的推理）<span class="muted">（补充说明）</span>：固定 $x_1,\dots,x_5$，对任意秘密 $s$ 和任意 $\mathbf y \in \mathbb F_q^5$，

$$
\Pr\big[(p(x_1),\dots,p(x_5)) = \mathbf y \;\big|\; \text{秘密} = s\big]
= \frac{\#\{(a_1,\dots,a_5) : \text{相容}\}}{q^5} = \frac{1}{q^5}.
$$

右边与 $s$ 无关，所以看到份额后，秘密的条件分布等于先验分布：5 份份额不泄露关于 $s$ 的**任何**信息。少于 5 份的情形，对上式中没看到的份额求和（边缘化）即可，结论相同。

<L02Shamir />

::: tldr
秘密放在 $p(0)$，随机系数补满 5 次；6 份插值即可恢复，5 份时每个候选秘密都恰好对应一个相容的多项式，份额的分布与秘密无关。
:::

## 2.10 从重传到纠错：两种故障 <Src p="22" />

<Fig src="/img/02/p022.jpg" cap="擦除（Erasure）：第 3 个位置缺失，位置已知；错误（Error）：有一个符号出错，但接收者不知道错在何处" p="22" />

- **擦除**<span class="en">Erasure</span>：某些位置丢了，但接收者**知道**是哪些位置；
- **错误**<span class="en">Error</span>：某些符号被改了，接收者**不知道**错在何处。

TCP/IP 常用**重传**来处理丢包；但重传的代价可能很高，也可能带来很大的延迟，甚至根本无法重传（比如深空探测器、已经写坏的磁盘）。**能不能预先加入冗余，让接收端直接恢复原来的消息？**

## 2.11 擦除：n + k 个取值就够了 <Src p="23" />

想发送 $n$ 个符号 $a_0, \dots, a_{n-1} \in \mathbb F_q$，信道最多擦除 $k$ 个位置。应该发送几个符号？

令 $p(x) = a_0 + a_1 x + \cdots + a_{n-1}x^{n-1}$，并发送 $p(\alpha_1), \dots, p(\alpha_{n+k})$，其中 $\alpha_i$ 两两不同（所以需要 $q \ge n+k$）。擦除 $k$ 个以后仍至少剩 $n$ 个点，位置已知，用拉格朗日插值恢复 $p$，再读出 $(a_0, \dots, a_{n-1})$。

**$n + k$ 足够**。稍后（2.13 节）用一个普适下界证明：它也恰好是最优的。

### 2.11.1 存储中的同一个问题：RAID <Src p="40" />

假设有 4 块磁盘 $A, B, C, D$。RAID 5 常用**分布式奇偶校验**<span class="en">Distributed parity</span>，使单块磁盘故障后仍能恢复数据。抽象地写成 $D = A \oplus B \oplus C$。若 $B$ 丢失：$B = D \oplus A \oplus C$。

<Fig src="/img/02/p040.jpg" size="sm" cap="A、B、C 三块数据盘加一块校验盘；B 坏了可以由其余三块异或恢复" p="40" />

这正是 $k = 1$ 个擦除的情形（磁盘坏了，位置已知），多存 1 块就够。更高等级的存储容错会使用更一般的纠删码（例如 Reed–Solomon 码），以容忍多处缺失或错误。

## 2.12 汉明距离：离散世界里的“稳定裕量” <Src p="24–25" />

::: def 汉明距离与最小距离 @P24
对 $s, t \in \mathbb F_q^m$，定义**汉明距离**<span class="en">Hamming distance</span>
$$
d(s,t) = \#\{i : s_i \ne t_i\}.
$$
对编码 $C$（把消息 $u$ 映成码字 $C(u)$），定义**最小距离**
$$
d_{\min}(C) = \min_{u \ne v} d\big(C(u), C(v)\big).
$$
:::

汉明距离满足三角不等式 $d(s,u) \le d(s,t) + d(t,u)$：$s_i \ne u_i$ 的位置上，$s_i \ne t_i$ 和 $t_i \ne u_i$ 至少有一个成立。<span class="muted">（补充说明）</span>

| 第一讲：连续扰动 | 这一讲：离散扰动 |
|---|---|
| 看输入误差会被放大多少 | **主动**把不同码字分得足够开 |
| 关注局部敏感性与条件数 | 关注不同码字之间的分离度 |

**鲁棒性的一种普遍策略：让不同合法对象之间留出足够的“安全裕量”**。

### 2.12.1 最小距离告诉我们能承受多少故障 <Src p="25" />

::: prin 最小距离与容错能力 @P25
- **$k$ 个擦除**：删掉任意 $k$ 个坐标后，不同码字仍必须可区分：$d_{\min} \ge k + 1$。擦除的位置是已知的。
- **$k$ 个错误**：同一个接收词不能同时距离两个合法码字都不超过 $k$：$d_{\min} \ge 2k + 1$。错误的位置未知，因此还必须排除“解码歧义”。
:::

课件的论证：若某个接收词 $r$ 同时满足 $d(r, C(u)) \le k$ 与 $d(r, C(v)) \le k$，则由三角不等式 $d(C(u), C(v)) \le 2k$。“所以要唯一纠正任意 $k$ 个错误，必须让不同码字之间满足 $d_{\min} \ge 2k+1$。”

<span class="muted">（注：这段论证的逻辑方向其实是“$d_{\min} \ge 2k+1$ ⇒ 不会有歧义”，即**充分性**；要说“必须”，还需要反方向的构造。下面把两个方向都补全。）</span>

**完整证明**<span class="muted">（补充说明）</span>

*擦除*。(⇐) 若 $d_{\min} \ge k+1$：设已知被擦除的位置集合为 $S$，$|S| \le k$。两个不同码字至少在 $k+1$ 个位置不同，其中至多 $k$ 个落在 $S$ 里，所以在 $S$ 之外仍有不同的位置——删去 $S$ 后它们仍可区分，解码唯一。(⇒) 若 $d_{\min} \le k$：取一对码字 $C(u), C(v)$，它们只在不超过 $k$ 个位置不同；信道恰好擦除这些位置，接收者看到的两个残缺词完全相同，无法区分。

*错误*。(⇐) 若 $d_{\min} \ge 2k+1$：由上面的三角不等式论证，任何接收词 $r$ 至多与一个码字距离 $\le k$，而真实码字与 $r$ 的距离 $\le k$，所以“找距离 $\le k$ 的码字”的答案唯一。(⇒) 若 $d_{\min} = d \le 2k$：取 $C(u), C(v)$ 恰在位置集合 $D$（$|D| = d$）上不同。构造 $r$：在 $D$ 之外与两者相同；在 $D$ 中取 $\lceil d/2\rceil$ 个位置抄 $C(u)$、其余 $\lfloor d/2\rfloor$ 个位置抄 $C(v)$。则
$$
d(r, C(u)) = \lfloor d/2 \rfloor \le k,\qquad d(r, C(v)) = \lceil d/2 \rceil \le k,
$$
即 $r$ 既可能是 $C(u)$ 错了 $\le k$ 个，也可能是 $C(v)$ 错了 $\le k$ 个——无法唯一解码。$\blacksquare$

## 2.13 Singleton 界：最少需要多少冗余？ <Src p="26–27" />

::: def 定理（Singleton 界） @P26
任意单射编码 $C : \mathbb F_q^n \to \mathbb F_q^m$，最小距离 $d = d_{\min}(C)$，都满足
$$
d_{\min} \le m - n + 1 .
$$
:::

**证明**：从每个码字删去**固定的** $d - 1$ 个坐标，得到映射 $C' : \mathbb F_q^n \to \mathbb F_q^{m-d+1}$。若两个不同消息 $u \ne v$ 删后的码字相同，那么 $C(u), C(v)$ 至多只在这 $d-1$ 个位置不同，$d(C(u), C(v)) \le d - 1 < d$，与最小距离为 $d$ 矛盾。因此 $C'$ 仍然单射，定义域的大小不超过值域的大小：

$$
q^n \le q^{m-d+1} \quad\Longrightarrow\quad n \le m - d + 1 \quad\Longrightarrow\quad d_{\min} \le m - n + 1. \qquad\blacksquare
$$

这不是 Reed–Solomon 码特有的性质；**任何**要编码 $q^n$ 条消息的 $q$ 元编码都必须满足这个上界。

**所以最少需要多少冗余？** 把 2.12 节的距离要求代入 Singleton 界：

$$
k \text{ 个擦除} \Rightarrow d_{\min} \ge k+1 \Rightarrow \boxed{m \ge n + k},\qquad
k \text{ 个错误} \Rightarrow d_{\min} \ge 2k+1 \Rightarrow \boxed{m \ge n + 2k}.
$$

因此，$n + 2k$ 不再只是“看起来够用”的猜测，而是**信息论意义下的最优目标**（擦除时 2.11 节的 $n+k$ 也就最优了）。

::: qa 多项式取值能恰好达到 m = n + 2k 这个极限吗？ @P27
**能**。在 $N = n + 2k$ 个不同点上发送消息多项式的取值（Reed–Solomon 码），最小距离恰好是 $2k + 1$，Singleton 界取等号（2.15 节证明）。原因还是“非零的次数 $< n$ 多项式至多有 $n-1$ 个根”。
:::

Alice 要传 $n$ 个符号，传输中至多 $k$ 个符号出错；要求 Bob 收到后要么判断没有错误并解码，要么发现至少有一个错误并丢弃（不需要纠正）。在 $GF(p)$（$p$ 为充分大的素数）上，Alice 应添加多少个符号、怎么选？证明方案可行，并证明添加更少的符号都不行。

**用到**：2.12 节“最小距离 ↔ 容错能力”的思路、本节的 Singleton 界、2.11 节的多项式取值编码；**思路方向**：先想清楚“能检测任意 $\le k$ 个错误”对 $d_{\min}$ 提出了什么要求（什么情况下 Bob 会把出错的码字误认为合法码字？），再把这个要求和本节的两个要求比较；上界用多项式取值构造，下界套 Singleton 界。

## 2.14 最小例子：2 个符号，1 个错误 <Src p="28" />

两个符号写成一条直线 $p(x) = a_0 + a_1 x$，在 4 个互不相同的位置发送取值 $p(\alpha_1), p(\alpha_2), p(\alpha_3), p(\alpha_4)$，其中最多 1 个收到的值被改坏（$n = 2$，$k = 1$，$N = n + 2k = 4$）。

<Fig src="/img/02/p028.jpg" size="sm" cap="4 个接收点中有 1 个是错误值；正确直线通过另外 3 个" p="28" />

- 4 个接收点中至少 3 个正确，所以**正确直线通过至少 3 个接收点**；
- 任何一条通过 3 个接收点的候选直线，至少经过 2 个正确点（3 个里至多 1 个是错的）；而两个正确点已经唯一决定原直线。

**所以通过至少 3 个接收点的直线唯一，就是原直线**。这就是 Reed–Solomon 纠错最简单的例子。

## 2.15 Reed–Solomon 码 <Src p="29–30" />

::: def Reed–Solomon 码 @P29
把消息编码成多项式 $p(x) = a_0 + a_1x + \cdots + a_{n-1}x^{n-1}$。选择两两不同的 $\alpha_1, \dots, \alpha_N \in \mathbb F_q$，$N = n + 2k$，并发送
$$
C(p) = \big(p(\alpha_1), \dots, p(\alpha_N)\big).
$$
最简单的做法是取 $q \ge N$，这样就有足够多互不相同的取值点。
:::

上一节是 $n = 2$，$k = 1$ 的情形。现在的问题只剩下：**为什么任意两个次数 $< n$ 的不同消息多项式，都能保持足够大的距离？**

::: prin 定理：Reed–Solomon 码恰好达到 Singleton 界 @P30
在 $N = n + 2k$ 个互不相同的点上取值的 Reed–Solomon 码满足 $d_{\min} = 2k + 1 = N - n + 1$。
:::

**证明**。取两个不同消息多项式 $p \ne \tilde p$。两个码字相同的坐标满足 $(p - \tilde p)(\alpha_i) = 0$。非零多项式 $p - \tilde p$ 的次数 $< n$，由 2.4.2 节的引理，这样的坐标最多有 $n-1$ 个。于是

$$
d_{\min} \ge N - (n-1) = 2k + 1 .
$$

另一方面，Singleton 界给出 $d_{\min} \le N - n + 1 = 2k + 1$。所以 $d_{\min} = 2k + 1$。$\blacksquare$

<span class="muted">（注：课件这两页把第二个消息多项式也记作 $q$，与域的大小 $q$ 撞了符号；这里改记为 $\tilde p$。）</span>

**另一种看上界的方式：直接构造达到距离的码字**<Src p="45" />。取任意次数 $< n$ 的多项式 $p$ 和任意非零 $c \in \mathbb F_q$，令

$$
\tilde p(x) = p(x) + c\prod_{j=1}^{n-1}(x - \alpha_j).
$$

$\tilde p$ 的次数仍 $< n$，于是 $p(\alpha_j) = \tilde p(\alpha_j)$（$j = 1, \dots, n-1$），但 $p \ne \tilde p$。而对 $j \ge n$，$c\prod_{i=1}^{n-1}(\alpha_j - \alpha_i) \ne 0$（各 $\alpha$ 互不相同，域中非零元之积非零），所以两个码字恰好在 $N - (n-1) = 2k+1$ 个位置不同。这给出 $d_{\min} \le 2k+1$，结合上面的下界，再次得到 $d_{\min} = 2k+1$。

**同一个关于根个数的事实，同时解释了拉格朗日插值的唯一性和 Reed–Solomon 码的距离**。

::: exam [作业] HW4 问题 2：多项式与纠错

**用到**：2.12 节最小距离与 $k$ 个错误的关系（两个方向）、本节“根的个数 ⇒ 距离”；注意记号对应：题中 $d$ 次多项式有 $d+1$ 个系数，相当于课件的“$n$”，所以 $d + 2k + 1$ 正是课件的 $N = n + 2k$。**思路方向**：按题目提示反证——若两个不同的 $d$ 次多项式各自至多与接收序列有 $k$ 处不一致，它们至少在多少个节点上相等？再用根的个数导出矛盾。提示的论证给出的是“$n \ge d+2k+1$ 时一定唯一”；题面说的是“必须”，想一想 $n \le d + 2k$ 时能否仿照本节 $\tilde p = p + c\prod(x-\alpha_j)$ 的构造和 2.12 节“抄一半”的接收词造出歧义。

## 2.16 唯一可解还不够：解码必须高效 <Src p="31" />

收到 $N = n + 2k$ 个值后，**朴素方法**可以枚举 $\binom{n+2k}{n}$ 个 $n$ 点子集：逐个插值，再检查它与多少个接收值一致。一般参数下这是指数级的。

朴素方法为什么正确？<span class="muted">（补充说明）</span>实际错误数 $e \le k$ 时，至少有一个 $n$ 点子集全是正确值，对它插值得到的就是 $p$，它与至少 $N - e \ge N - k$ 个接收值一致；反过来，任何与至少 $N - k$ 个接收值一致的次数 $< n$ 的多项式，其码字与接收词距离 $\le k$，由 $d_{\min} = 2k+1$ 的唯一性只能是 $p$。所以“找到一个与 $\ge N-k$ 个值一致的插值多项式就停”是对的，只是可能要试很多子集。

**Berlekamp–Welch**：用一个多项式表示错误位置，最后把解码问题转化为一个**线性方程组**。课件把推导放在补充材料，这里直接接上。

### 2.16.1 错误位置对应一个“消失多项式” <Src p="42" />

发送 $p(\alpha_1), \dots, p(\alpha_N)$，收到 $r_1, \dots, r_N$；实际有 $e \le k$ 个错误，错误位置记为 $f_1, \dots, f_e$。定义**错误定位多项式**<span class="en">Error-locator polynomial</span>

$$
E_0(x) = \prod_{j=1}^e (x - \alpha_{f_j}),\qquad \deg E_0 \le k,
$$

令 $Q_0(x) = p(x)E_0(x)$，$\deg Q_0 \le n + k - 1$。那么对**每一个**接收位置 $i$ 都有

$$
Q_0(\alpha_i) = r_i E_0(\alpha_i) .
$$

- 错误位置：$E_0(\alpha_i) = 0$，两边都是 0，错误值被自动“消掉”；
- 正确位置：$r_i = p(\alpha_i)$，两边都是 $p(\alpha_i)E_0(\alpha_i)$。

### 2.16.2 把 Q、E 直接当作未知量 <Src p="43" />

我们不知道错误位置，因此也不知道 $E_0$。直接寻找多项式 $Q, E$，满足 $\deg Q \le n + k - 1$，$\deg E \le k$，以及 $N = n + 2k$ 个**齐次线性方程**

$$
Q(\alpha_i) = r_i E(\alpha_i),\qquad i = 1, \dots, N.
$$

$r_i$、$\alpha_i$ 都已知，所以这是关于 $Q, E$ 的系数的线性方程。未知系数一共有 $(n+k) + (k+1) = N + 1$ 个，比方程多一个，所以这 $N$ 个齐次方程**一定存在非零解** $(Q, E)$（$(Q_0, E_0)$ 本身就是一个非零解）。

而 $E$ 不可能恒为 0：否则 $Q(\alpha_i) = 0$ 对 $N$ 个不同点成立，但 $\deg Q \le n+k-1 < N$，由根的个数引理 $Q$ 也恒为 0，与“非零解”矛盾。

### 2.16.3 为什么任意非零解都能恢复原来的 p？ <Src p="44" />

取上一步的**任意**非零解 $(Q, E)$。至少有 $N - e \ge N - k = n + k$ 个位置是正确的；在这些位置 $r_i = p(\alpha_i)$，于是

$$
Q(\alpha_i) - p(\alpha_i)E(\alpha_i) = Q(\alpha_i) - r_iE(\alpha_i) = 0 .
$$

但 $\deg(Q - pE) \le \max(n+k-1,\ (n-1) + k) = n + k - 1$。一个次数至多 $n+k-1$ 的多项式却有至少 $n+k$ 个不同零点，因此 $Q \equiv pE$。$E \ne 0$，所以恢复出的商唯一：

$$
\boxed{\,p = Q / E\,}
$$

**算法**<span class="muted">（补充说明）</span>：(1) 列出 $N \times (N+1)$ 的齐次方程组，在 $\mathbb F_q$ 上做高斯消元求一个非零解，$O(N^3)$ 次域运算；(2) 做一次多项式除法 $Q/E$，$O(N^2)$。若除不尽或商的次数 $\ge n$，就说明错误超过 $k$ 个。另外，错误位置一定是 $E$ 的根：在错误位置 $r_i \ne p(\alpha_i)$，而 $p(\alpha_i)E(\alpha_i) = Q(\alpha_i) = r_iE(\alpha_i)$，只能 $E(\alpha_i) = 0$。

## 2.17 Reed–Solomon 在哪里出现？ <Src p="41" />

Reed–Solomon 码以及更一般的纠删码，被广泛用于：

- 深空通信与数字图像传输；
- 分布式存储、RAID 和对象存储；
- 光盘、二维码等存储或通信系统；
- 混合检测（pooled testing）等利用“冗余观察”恢复信息的场景。

实际中的错误往往会成片出现，形成**突发错误**<span class="en">Burst errors</span>：相邻比特或符号可能一起受损。因此工程实现通常还会配合交织（interleaving）、分块等技术，并采用更复杂的编码方案。

### 2.17.1 多项式插值与成功率放大 <Src p="47" />

假设函数本身是低次多项式，并且次数上界已知。如果某个算法在很多输入点上都有不低的概率给出正确值，那么可以：

1. 查询足够多的点；
2. 把这些答案看成一个可能含有错误的码字；
3. 通过纠错恢复整个低次多项式；
4. 从而在所有点上正确计算它。

**低次数表示 + 冗余查询 ⟹ 把“多数时候正确”提升为“处处正确”**。

### 2.17.2 课外阅读：Permanent 的随机自归约 <Src p="48" />

对 $n\times n$ 矩阵 $A, B$，把它们之间的仿射直线参数化为 $g(t) = \operatorname{perm}(A + tB)$。积和式（permanent）是矩阵元素的 $n$ 次多项式，所以 $g(t)$ 是次数至多 $n$ 的一元多项式。若我们能在足够多个随机选取的 $t$ 上可靠地计算 $g(t)$，就可以利用插值或纠错恢复整个 $g$，进而得到目标值 $g(0) = \operatorname{perm}(A)$。

这是 TCS 中常见的**随机自归约**<span class="en">Random self-reducibility</span>思想：把一个最坏输入嵌入一条低次多项式曲线，再从随机点恢复回来。

## 2.18 一次小结：两个事实，三种计算任务 <Src p="32" />

| 事实 1：维数与唯一性 | 事实 2：根的个数与分离度 |
|---|---|
| $p \in \mathcal P_{<n}$，$n$ 个互异取值 ⟹ 唯一决定 $p$ | $p \ne \tilde p$，$\deg(p - \tilde p) < n$ ⟹ $p - \tilde p$ 至多 $n-1$ 个根 |
| $m = n$：插值与精确重建 | 多给一些取值，可以把不同码字分得更开 |
| $m < n$：再加随机化 ⟹ 秘密分享 | $m > n$：冗余 ⟹ 纠删与纠错 |

**表示、信息、冗余本质上都在问：有限个坐标究竟携带了多少关于整体的信息？**

::: tldr
最小距离 $d_{\min}$ 决定容错能力（$k$ 擦除要 $k+1$，$k$ 错误要 $2k+1$），Singleton 界说冗余至少 $k$ / $2k$；Reed–Solomon 码恰好取到等号，Berlekamp–Welch 把解码化成一个线性方程组。
:::

## 2.19 代数上能恢复，不代表数值上逼近得好 <Src p="33" />

在有限域里，只要横坐标互不相同，我们主要关心**能不能精确恢复**。在 $\mathbb R$ 上，给定一个真实函数 $f$，我们却还要问：

$$
P(x) \text{ 在采样点之间到底离 } f(x) \text{ 多远？}
$$

::: warn 插值（Interpolation）≠ 逼近（Approximation） @P33
“在采样点上误差为 0”并不意味着“在整个区间上都很接近”。
:::

## 2.20 拉格朗日插值误差公式 <Src p="34" />

::: def 定理（插值余项） @P34
设 $f$ 在包含 $x, x_1, \dots, x_n$ 的区间上 $n$ 次连续可导，$P$ 是在 $x_1, \dots, x_n$ 上的次数 $\le n-1$ 插值多项式。那么对每个 $x$，存在某个 $\xi_x$ 落在这些点所张成的最小区间内，使得
$$
f(x) - P(x) = \frac{f^{(n)}(\xi_x)}{n!}\prod_{j=1}^n (x - x_j).
$$
:::

它和**泰勒余项**<span class="en">Taylor remainder</span>具有相同的结构：都是“高阶导数 × 几何因子”；这里只是一个展开点被 $n$ 个插值节点取代。

| 函数本身的难度 | 我们选择的采样点 |
|---|---|
| $f^{(n)}$ | $\prod_{j=1}^n (x - x_j)$ |

### 2.20.1 证明：为什么会出现 n 阶导数？ <Src p="46" />

记 $I$ 为包含 $x, x_1, \dots, x_n$ 的最小闭区间。

1. **$x$ 是节点**：若 $x = x_j$，左边 $f(x_j) - P(x_j) = 0$，右边乘积中有因子 $x - x_j = 0$，任取 $\xi_x$ 都成立。<span class="muted">（补充说明：课件的 $\lambda$ 需要 $\omega(x) \ne 0$，所以要单独处理这一情形。）</span>
2. **构造辅助函数**：设 $x$ 不是节点。令
   $$
   \omega(t) = \prod_{j=1}^n (t - x_j),\qquad \lambda = \frac{f(x) - P(x)}{\omega(x)},\qquad \phi(t) = f(t) - P(t) - \lambda\,\omega(t).
   $$
   $\omega(x) \ne 0$，所以 $\lambda$ 有定义。
3. **数零点**：$\phi(x_j) = f(x_j) - P(x_j) - \lambda\cdot 0 = 0$（插值条件）；$\phi(x) = f(x) - P(x) - \lambda\omega(x) = 0$（$\lambda$ 的定义）。所以 $\phi$ 在 $I$ 中有 $n+1$ 个不同的零点 $x, x_1, \dots, x_n$。
4. **反复用 Rolle 定理**：$\phi$ 与 $f$ 一样 $n$ 次可导。$n+1$ 个零点把 $I$ 分成 $n$ 段，每段内由 Rolle 定理 $\phi'$ 有一个零点，所以 $\phi'$ 在 $I$ 中至少 $n$ 个不同零点；同理 $\phi''$ 至少 $n-1$ 个……共应用 Rolle 定理 $n$ 次，$\phi^{(n)}$ 在 $I$ 中至少有一个零点 $\xi$。
5. **算 $n$ 阶导数**：$P$ 次数 $\le n-1$，所以 $P^{(n)} = 0$；$\omega$ 是首项系数为 1 的 $n$ 次多项式，所以 $\omega^{(n)} = n!$。于是
   $$
   0 = \phi^{(n)}(\xi) = f^{(n)}(\xi) - \lambda\, n! \quad\Longrightarrow\quad \lambda = \frac{f^{(n)}(\xi)}{n!}.
   $$
6. 代回 $\lambda$ 的定义，即 $f(x) - P(x) = \lambda\,\omega(x) = \dfrac{f^{(n)}(\xi)}{n!}\prod_j (x - x_j)$，取 $\xi_x = \xi$。$\blacksquare$

## 2.21 等距点为什么会出问题？Runge 现象 <Src p="35" />

<Fig src="/img/02/p035.jpg" size="md" cap="f(x) = 1/(1 + 25x²) 与它在 11 个等距点上的次数 ≤ 10 插值" p="35" />

对 $f(x) = 1/(1+25x^2)$ 在 $[-1,1]$ 上取 11 个等距点做次数 $\le 10$ 的插值：所有节点上都有 $P(x_i) = f(x_i)$，但是在**端点附近**，$P$ 出现很大的振荡（最大误差约 1.92，比 $f$ 本身的最大值 1 还大）。提高次数虽然增加了自由度，却**不能保证整体误差变小**。这就是 **Runge 现象**。

用误差公式看原因<span class="muted">（补充说明）</span>：两个因子都在作怪。一方面，$f$ 在复平面上有极点 $\pm \mathrm i/5$，离实轴很近，$\max|f^{(n)}|/n!$ 大约按 $5^n$ 增长，并不随 $n$ 变小；另一方面，等距节点的几何因子 $|\omega(x)|$ 在区间两端比中间大得多（下面演示的下图）。两者相乘，端点附近的误差随 $n$ 指数增长。

## 2.22 选点本身就是算法设计的一部分 <Src p="36" />

误差公式给出

$$
|f(x) - P(x)| \le \frac{\max_{\xi}|f^{(n)}(\xi)|}{n!}\,\Big|\prod_{j=1}^n (x - x_j)\Big| .
$$

第一个因子由 $f$ 决定，第二个因子由我们决定。若我们可以自己选择两两不同的 $x_1, \dots, x_n$，自然会问

$$
\min_{x_1,\dots,x_n \in [-1,1]}\ \max_{x \in [-1,1]}\ \Big|\prod_{j=1}^n (x - x_j)\Big| .
$$

不同的节点在**代数上**都能唯一确定插值多项式；在**数值上**却远非等价。这已经是一个**极小极大**<span class="en">Minimax</span>的算法设计问题。

预告：最优节点不是等距的，而会在区间两端更加密集。

::: qa 不同的插值节点都能唯一确定插值多项式，为什么数值表现却会相差很大？ @P38
唯一性只是代数事实；误差 $f - P$ 里有一个完全由节点决定的几何因子 $\prod_j (x - x_j)$。等距节点让这个因子在端点附近特别大，节点往两端加密就能把它“压平”。下一讲会解出上面的极小极大问题：最优节点是 **Chebyshev 点**，此时 $\max|\prod(x - x_j)| = 2^{1-n}$。在上面的演示里切换到“Chebyshev 点”即可对比。
:::

::: tldr
插值误差 = $\frac{f^{(n)}(\xi)}{n!}\times\prod(x-x_j)$：函数难度乘以节点的几何因子。等距节点的几何因子两端过大，高次插值会在端点振荡（Runge 现象）；选点是算法设计的一部分。
:::

## 2.23 不要求经过每个点：一致逼近 <Src p="49–55" />

插值要求 $P(x_i) = f(x_i)$。如果不要求精确经过指定点，而只希望**整体尽可能接近**，就进入**函数逼近**<span class="en">Approximation</span>：

$$
\|f\|_\infty := \sup_x |f(x)|,\qquad \min_{\deg p \le n} \|f - p\|_\infty .
$$

::: def Weierstrass 逼近定理 @P49
对闭区间上的连续函数 $f$ 和任意 $\varepsilon > 0$，都存在多项式 $p$ 使 $\|f - p\|_\infty < \varepsilon$。
:::

下面用概率给出一个构造性证明（Bernstein）。先在 $[0,1]$ 上证明；一般区间 $[a,b]$ 用仿射变换 $x \mapsto a + (b-a)x$ 换过去，多项式仍是多项式。

### 2.23.1 概率论回顾 <Src p="50" />

随机变量 $X$ 的期望与方差：$\mathbb E[X] = \sum_x x\Pr[X = x]$，$\operatorname{Var}(X) = \mathbb E[(X - \mathbb EX)^2]$。

::: prin Chebyshev 不等式 @P50
对任意 $t > 0$，
$$
\Pr\big[|X - \mathbb EX| \ge t\big] \le \frac{\operatorname{Var}(X)}{t^2}.
$$
:::

下一步要用一个**集中在 $x$ 附近**的随机变量，自动构造逼近 $f(x)$ 的多项式。

### 2.23.2 Bernstein 多项式：用二项分布取样 <Src p="51–52" />

给定连续函数 $f : [0,1] \to \mathbb R$，固定 $x \in [0,1]$。令 $K \sim \operatorname{Bin}(n, x)$，即 $K$ 是 $n$ 次伯努利试验（Bernoulli trials）中的成功次数，每次成功的概率为 $x$。那么

$$
\mathbb E[K] = nx,\qquad \operatorname{Var}(K) = nx(1-x).
$$

（推导：$K = X_1 + \cdots + X_n$，$X_i$ 独立、取 1 的概率为 $x$。$\mathbb E X_i = x$，$\operatorname{Var} X_i = \mathbb E X_i^2 - x^2 = x - x^2$；期望可加，独立随机变量的方差也可加。<span class="muted">补充说明</span>）

因此，随着 $n$ 增大，$K/n$ 会越来越集中在 $x$ 附近（$\operatorname{Var}(K/n) = x(1-x)/n \to 0$）。**如果 $K/n \approx x$，连续性就意味着 $f(K/n) \approx f(x)$**。

因为 $\Pr[K = i] = \binom ni x^i(1-x)^{n-i}$，

$$
B_nf(x) := \mathbb E\Big[f\Big(\frac Kn\Big)\Big] = \sum_{i=0}^n f\Big(\frac in\Big)\binom ni x^i(1-x)^{n-i}.
$$

::: def Bernstein 基函数 @P52
$b_{n,i}(x) = \binom ni x^i (1-x)^{n-i}$。每个 $b_{n,i}$ 是次数 $n$ 的多项式，$f(i/n)$ 只是常数，所以 **$B_nf = \sum_i f(i/n)\, b_{n,i}$ 是次数至多 $n$ 的多项式**。
:::

### 2.23.3 为什么 B<sub>n</sub>f 一致收敛到 f？ <Src p="53–54" />

记 $f$ 的**连续模**为 $\omega_f(\varepsilon) = \sup_{|x-y|\le\varepsilon} |f(x) - f(y)|$。对任意 $\varepsilon > 0$，把事件分成 $|K/n - x| \le \varepsilon$ 和 $|K/n - x| > \varepsilon$ 两类：

$$
\begin{aligned}
|f(x) - B_nf(x)| &= \Big|\mathbb E\Big[f(x) - f\Big(\frac Kn\Big)\Big]\Big| \le \mathbb E\Big|f(x) - f\Big(\frac Kn\Big)\Big| \\
&\le \omega_f(\varepsilon)\cdot\Pr\Big[\Big|\frac Kn - x\Big| \le \varepsilon\Big] + 2\|f\|_\infty\Pr\Big[\Big|\frac Kn - x\Big| > \varepsilon\Big] \\
&\le \omega_f(\varepsilon) + 2\|f\|_\infty\Pr\Big[\Big|\frac Kn - x\Big| > \varepsilon\Big].
\end{aligned}
$$

（第一行：$f(x)$ 是常数，可以移进期望，再用 $|\mathbb E Y| \le \mathbb E|Y|$；第二行：第一类事件中 $|f(x) - f(K/n)| \le \omega_f(\varepsilon)$，第二类中 $|f(x) - f(K/n)| \le |f(x)| + |f(K/n)| \le 2\|f\|_\infty$。<span class="muted">补充说明</span>）

由 Chebyshev 不等式（取 $t = n\varepsilon$，并注意 $\{>\} \subseteq \{\ge\}$）和 $x(1-x) \le \frac14$：

$$
\Pr\Big[\Big|\frac Kn - x\Big| > \varepsilon\Big] \le \Pr\big[|K - nx| \ge n\varepsilon\big] \le \frac{nx(1-x)}{n^2\varepsilon^2} = \frac{x(1-x)}{n\varepsilon^2} \le \frac{1}{4n\varepsilon^2}.
$$

::: prin Bernstein 的定量误差 @P54
对任意 $x \in [0,1]$、$\varepsilon > 0$：
$$
|f(x) - B_nf(x)| \le \omega_f(\varepsilon) + \frac{\|f\|_\infty}{2n\varepsilon^2}.
$$
**概率集中**控制“采样点离 $x$ 多远”；**一致连续性**控制“函数值因此变化多少”。
:::

**收尾：为什么是一致收敛**<span class="muted">（补充说明，课件停在上面的界）</span>。$[0,1]$ 是闭区间，连续函数在其上一致连续（Cantor 定理），即 $\omega_f(\varepsilon) \to 0$（$\varepsilon \to 0$）。给定 $\eta > 0$，先取 $\varepsilon$ 使 $\omega_f(\varepsilon) < \eta/2$，再取 $n > \|f\|_\infty/(\eta\varepsilon^2)$ 使第二项 $< \eta/2$。两步的选择都与 $x$ 无关，所以 $\|f - B_nf\|_\infty < \eta$。这就证明了 $[0,1]$ 上的 Weierstrass 定理。$\blacksquare$

与插值对比：$B_nf$ 一般**不经过** $(i/n, f(i/n))$，收敛也慢（对 $|x - \frac12|$ 这样的函数大约是 $1/\sqrt n$），但它对**任何**连续函数都收敛——正好和 Runge 现象形成对照。

<L02Bernstein />

### 2.23.4 Stone–Weierstrass 与更一般的函数逼近 <Src p="55" />

Weierstrass：多项式在 $C([a,b])$ 中对 $\|\cdot\|_\infty$ 稠密。更一般地：

::: def Stone–Weierstrass 定理 @P55
在紧 Hausdorff 空间 $X$ 上，若实连续函数的子代数 $A \subseteq C(X, \mathbb R)$
- 包含常数函数；
- 分离点：$x \ne y \Rightarrow \exists f \in A$ 使 $f(x) \ne f(y)$，

那么 $A$ 在 $C(X,\mathbb R)$ 中对 $\|\cdot\|_\infty$ 稠密。
:::

（多项式全体在 $[a,b]$ 上包含常数、且 $f(x) = x$ 就能分离点，所以 Weierstrass 是它的特例。<span class="muted">补充说明</span>）

神经网络的**通用逼近**<span class="en">Universal approximation</span>也可以看作“某个函数类是否稠密”的问题；但具体定理取决于网络模型本身的结构，不能把所有网络都直接套用 Stone–Weierstrass 定理。

::: tldr
不要求过点时，Bernstein 多项式 $B_nf(x) = \mathbb E[f(K/n)]$ 用二项分布的集中性证明了 Weierstrass 定理：误差 $\le \omega_f(\varepsilon) + \|f\|_\infty/(2n\varepsilon^2)$，对任意连续函数一致收敛。
:::

## 2.24 本讲区分了两个不同的问题 <Src p="37" />

| 精确重建：对象本来就属于模型类 | 数值逼近：多项式只是对真实函数的近似 |
|---|---|
| $p \in \mathcal P_{<n}$，$n$ 个互异取值已经是完整坐标 | $P(x_i) = f(x_i)$：节点上完全正确，节点之间仍可能很差 |
| 刚好给够：拉格朗日插值 | 误差取决于两部分：$\underbrace{f^{(n)}}_{\text{函数的光滑性}}$ 和 $\underbrace{\prod_j (x - x_j)}_{\text{插值节点的位置}}$ |
| 故意少给：Shamir 秘密分享 | |
| 故意多给：Reed–Solomon 冗余与纠错 | |

**能唯一恢复，并不意味着逼近得好**。

### 2.24.1 下节课：Chebyshev 多项式与逼近 <Src p="38" />

本讲留下的问题：不同的插值节点都能唯一确定插值多项式，为什么数值表现却会相差很大？下一讲将解这个极小极大问题

$$
\min_{x_1,\dots,x_n \in [-1,1]}\ \max_{x\in[-1,1]}\ \Big|\prod_{j=1}^n (x - x_j)\Big|,
$$

并进一步区分**插值**与**函数逼近**。后续路线：函数逼近与正交多项式 ⟶ 最小二乘法与最佳平方逼近。

- 最少冗余：擦除 $m \ge n+k$，错误 $m \ge n+2k$
